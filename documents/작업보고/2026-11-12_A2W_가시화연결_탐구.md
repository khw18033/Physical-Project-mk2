# 탐구 보고: Unitree A2-W 를 가시화에 붙이는 길

**날짜**: 2026-11-12
**근거 문서**: `Unitree A2-W 내부 개발 PC 접속 제어 방식 조사.md`(2026-11-11) · `documents/규약/장치연동_공통규약_260924.md` · `documents/규약/장치연동_부록A_로보마스터EP_260924.md` · `web-integration.md`
**상태**: 탐구만 함 — **코드 수정 없음.** 실물 확인 전이라 A2-W 쪽 값은 A2 Pro 기준 추정이다

> 한 줄 요약 — A2-W 의 개발용 PC(PC2)에 **장치 노드와 MQTT 브로커**를 올리고 Go1 과 같은 공통 규약으로 말하게 한다.
> 그러면 가시화는 연결 관리에 `ws://<PC2>:9001/mqtt` 한 줄을 더하는 것으로 상태 카드 · 정량 명령 · 정지 버튼이 그대로 붙는다.
> 노드는 HW 노드 코드에 연결 클래스 `A2Link` 하나를 더하는 모양이다.

---

## 1절 — 왜 PC2 에 노드를 두는가

| 사실 | 근거 | 결론 |
|---|---|---|
| A2 SDK(DDS)는 내부 제어망(123 대역)에 닿는 PC2 에서만 돈다. 노트북은 124 대역에서 PC2 까지만 간다 | 조사 md §하드웨어·네트워크 구조 | 명령을 SDK 호출로 바꾸는 노드는 **PC2 에 둘 수밖에 없다** |
| 웹은 기종 표가 아니라 장치가 밝힌 것(capability · registration · 토픽)으로 장비를 알아본다 | `viz-debugger/src/physical/deviceIdentity.ts` 머리 주석 | A2 가 `robot` 으로 자기소개만 하면 **웹 코드 수정이 필요 없다** |
| 한 브로커에 명령을 받는 장비가 둘이면 웹은 대상을 고르지 않는다(「애매하면 안 쏜다」) | `deviceIdentity.ts` `resolve()` · `pick()` | **pi7 브로커를 같이 쓰면 Go1 과 A2 명령이 둘 다 막힌다.** A2 전용 브로커가 필요하다 |
| HW 로봇 노드는 기종별 연결만 `ControllerLink` 로 갈아 끼운다(`sim` · `go1` · `ep`) | `raspi/pi7/hw/pi/robot/controller_link.py` 88–104행 · `common/config.py` `CONTROLLER_LINK` | `read_state` · `send_command` · `link_health` 셋을 채운 `A2Link` 하나로 노드 본체 · 명령 처리 · LWT 를 그대로 쓴다 |

## 2절 — 구성

```
관제 웹(노트북) ──ws:9001──▶ mosquitto (PC2) ◀──1883── a2-node (PC2) ──DDS, 123 대역──▶ PC1 (보행 제어)
노트북 유선 = 192.168.124.100 (PC2 쪽 포트)           unitree_sdk2_python: SportClient · rt/lf/sportmodestate
노트북 Wi-Fi = 연구실 망 (pi7 · pi3 는 지금처럼)
```

- 웹은 브로커 여러 개에 동시에 붙는다(공통 규약 §2). Go1(pi7) · 드론(pi3) · A2(PC2)가 각자 브로커를 갖는 모양이 된다.
- DDS 는 PC2 안에만 머문다. 노트북에 DDS · ROS 2 를 깔 필요가 없다.

## 3절 — 검토한 안

| 안 | 판단 |
|---|---|
| **A. PC2 에 노드 + 브로커 (추천)** | pi7 · pi3 와 같은 모양이고 규약 그대로다. PC2 에 mosquitto 설치 승인이 필요하다 |
| A'. 노드만 PC2, 브로커는 별도 파이나 노트북 | PC2 설치가 막힐 때의 대안. 노드의 `BROKER_HOST` 만 바꾼다. **A2 전용 브로커여야 한다**는 조건은 같다 |
| B. 노트북에서 DDS / ROS 2 로 직접 받기 | 노트북은 123 대역에 못 닿는다. 웹에 ROS 어댑터를 따로 짜야 해서 공통 규약 §1 과 어긋난다. **버린다** |
| C. 게이트웨이가 SSH 로 예제 스크립트 실행(드론 비행 실행기 B안 방식) | 첫 「움직인다」 확인으로는 빠르다. 상태가 안 오고 `abort` 가 안 먹고 결과가 없다. **본 연결로는 안 맞는다** |

## 4절 — a2-node 가 할 일 (공통 규약 기준)

**식별자 [제안]**

| 항목 | 값 |
|---|---|
| `entity_id` / clientId / `Command.target` | `a2w-001` |
| `entity_type` | `robot` |
| `device_type` | `unitree_a2w` |
| Capability | `["ping", "diag", "turn", "move_forward", "abort"]` |
| 토픽 | `terminal/a2w-001/{downlink,uplink}` · `zoneA/robot/a2w-001/{status,state,heartbeat}` |
| 영상 소스 키 | `a2w-001_front` 등 (카메라 구성 미확인) |

**SDK 와 규약의 대응**

| 규약 | SDK | 주의 |
|---|---|---|
| `position{x, y, heading_deg}` · `speed_mps` · `robot_mode` | `rt/lf/sportmodestate` 의 위치 · 속도 · FSM 모드 | 좌표 원점과 yaw 기준은 부록에 적는다 |
| `battery_pct` | 미확인 (sportmodestate 에 없을 수 있음) | 없으면 **`null`.** 0 을 넣지 않는다 |
| `turn{deg}` | `SportClient.Move(0, 0, vyaw)` 를 yaw 로 닫는 반복 | 규약은 **+ = 시계방향(오른쪽).** Unitree yaw 는 보통 반시계 + 라 노드에서 부호를 뒤집을 가능성이 크다 — 책상 위에서 눈으로 확인 |
| `move_forward{distance_m, vx}` | `Move(vx, 0, 0)` 를 위치로 닫는 반복 | 범위 밖 값은 잘라 쓰지 말고 `INVALID_ARGUMENT` |
| `abort` | `StopMove` | **`Damp` 는 쓰지 않는다**(힘이 빠져 주저앉는다). 거부하지 않고, 여러 번 와도 같게 |

**자체 안전장치** — 브로커 연결이 끊기면 멈춘다. 명령 하나에 거리 · 시간 상한을 둔다. 조종기 비상정지(`L2`+`B`)는 별개로 살려 둔다.

## 5절 — 미리 알아둘 걸림돌

1. **파이썬 판.** `controller_link.py` 47행 등이 `float | None` 을 dataclass 필드에 쓰고 `from __future__ import annotations` 가 없다 — **파이썬 3.10 이상**이어야 import 된다. 조사 md 의 빌드 환경(Ubuntu 20.04)은 기본 3.8 이다. PC2 에 3.10+ venv 를 따로 두거나, 그 한 줄이 필요하다.
2. **바퀴형 서비스 이름.** B2-W 는 `wheeled_sport` 를 따로 쓴다. A2-W 가 `sport` 인지, 예제 `a2_sport_client` 가 그대로 도는지 모른다.
3. **카메라 직접 보기.** `viz-debugger/src/physical/cameraView.ts` 58행이 Go1(`go1_robot`) · 드론만 갈라 둔다. A2 는 백엔드 `/media` 로 빠진다. 직접 보려면 나중에 몇 줄 더해야 한다.
4. **음성 · 생성 어휘.** `registry.json`(게이트웨이 · STT · 생성이 같이 읽음)에 `a2w-001` 이 있어야 「A2 앞으로 1m」 같은 발화가 잡힌다.
5. **망.** 노트북은 유선으로 PC2, Wi-Fi 는 연구실 망. PC2 를 Wi-Fi · Tailscale 에 붙이는 것은 무선 SSH 가 미확인이고 비밀번호부터 바꿔야 해서 뒤로 미룬다.

## 6절 — 추천 순서

| 단계 | 할 일 | 웹에서 보이는 것 |
|---|---|---|
| 0 | 실물 확인(7절) | — |
| 1 | PC2 에 브로커 + 노드, 연결은 `CONTROLLER_LINK=sim` | 카드가 뜨고 `ping` 성공. 공통 규약 §11 점검 1~8 을 로봇을 안 움직이고 끝낸다 |

| 4 | 카메라 · 부록(로보마스터 부록 A 양식으로 「부록 E — A2-W」) | 영상 |

## 7절 — 실물에서 확인할 것

- [ ] PC2 의 실제 IP · 계정 · Ubuntu 판 · 파이썬 판 · `unitree_sdk2` 설치 여부
- [ ] `a2_sport_state` 출력 — 배터리 칸이 있는가, 위치 원점, yaw 부호
- [ ] A2-W 보행 서비스 이름(`sport` / 바퀴형 별칭)과 `a2_sport_client` 동작 여부
- [ ] PC2 에 mosquitto · 파이썬 venv 를 설치해도 되는지 담당자 승인 (안 되면 A' 안)
