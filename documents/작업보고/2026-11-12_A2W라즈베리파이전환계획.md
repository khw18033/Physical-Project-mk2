# A2-W 라즈베리파이 전환 계획 (2026-11-12)

현재 구현: [2026-11-12_A2W가시화연동.md](2026-11-12_A2W가시화연동.md)

## 요약

- **지금:** 노트북을 PC2 항공 커넥터에 유선으로 직접 꽂아 쓴다. 브로커(mosquitto)와 카메라 서버도 PC2에서 돈다.
- **목표:** Go1(pi7)과 같은 모양으로 바꾼다.
  - 로봇 위에 새 라즈베리파이를 하나 싣고, PC2와 랜선으로 연결한다.
  - Pi가 Wi-Fi, Tailscale, 브로커를 맡는다.
  - 웹은 장소와 상관없이 `ws://<pi>.tailcb6bfb.ts.net:9001/mqtt` 하나로 붙는다.
- **브리지는 PC2에 남는다.** PC1의 DDS는 123 대역(PC2 `eth0`)에만 나온다. Pi는 124 대역에 붙어서 DDS를 볼 수 없다.
  - Pi를 123 제어망에 직접 붙이는 것은 하지 않는다. 빈 포트가 없고, PC1–PC2 제어망은 건드리지 않는다는 원칙 때문이다.
- **PC2는 거의 그대로다.** 브리지의 브로커 주소만 Pi로 바꾸고 PC2의 mosquitto를 끈다. 카메라는 Pi가 중계한다.

## 1. 목표 구성

```
                      로봇 위
┌───────────────────────────────────────────────────────────────┐
│  PC1 ──DDS(123)── PC2 (a2_bridge.py, 카메라 :8090)            │
│                    │ net1 192.168.124.162                     │
│                    │ 항공 커넥터 (이더넷 + 12V)               │
│                    ▼                                          │
│                   Pi  eth0  192.168.124.50/24                 │
│                       mosquitto 1883 (124 대역) · 9001 (ws)   │
│                       카메라 중계 :8090 → PC2:8090            │
│                       wlan0 → 연구실 Wi-Fi / 휴대폰 핫스팟     │
│                       tailscale0                              │
└───────────────────────────────────────────────────────────────┘
                         │ Tailscale
                         ▼
                   가시화 웹 (노트북 · 발표장 PC)
```

| 구간 | 지금 (노트북 직결) | 전환 후 |
|---|---|---|
| 브리지 → 브로커 | PC2 `127.0.0.1:1883` | Pi `192.168.124.50:1883` (`--broker 192.168.124.50`) |
| 웹 → 브로커 | `ws://192.168.124.162:9001/mqtt` | `ws://<pi>.tailcb6bfb.ts.net:9001/mqtt` |
| 웹 → 카메라 | `http://192.168.124.162:8090/stream/1` | `http://<pi>.tailcb6bfb.ts.net:8090/stream/1` (Pi가 PC2로 중계) |
| 노트북 위치 | 로봇 옆, 랜선 | 같은 Tailscale 망이면 어디서든 |

**웹 코드는 바꾸지 않아도 된다.**
- 카메라 주소는 "브로커 호스트:8090"으로 만든다(`cameraView.ts`의 `A2_CAMVIEW_PORT`).
- 그래서 Pi가 같은 포트로 중계하면 브로커 주소만 바꿔도 카메라가 따라온다.
- Go1의 pi7(8090 카메라 뷰어)과 같은 규칙이다.

## 2. 준비물

| 항목 | 내용 | 비고 |
|---|---|---|
| 라즈베리파이 | Pi 4(4 GB 이상) 또는 Pi 5, 64비트 OS | Go1의 pi7과 같은 OS를 쓰면 설정을 그대로 옮길 수 있다 |
| 유선 연결 | 항공 커넥터 변환 케이블(지금 노트북에 쓰는 것) + Pi 랜 포트 | 링을 끝까지 돌려 잠가야 링크가 잡힌다 |
| 전원 | 보조배터리(5 V 3 A 이상) 또는 12 V → 5 V 강압 모듈 | 항공 커넥터의 12 V를 쓰려면 **핀 배치와 허용 전류를 먼저 확인**한다 |
| 무선 | Pi 내장 Wi-Fi | 실외는 휴대폰 핫스팟이나 USB LTE 동글 |
| 고정 | 로봇 등판 거치대, 케이블 정리 | 바퀴, 관절 가동 범위를 피한다 |

## 3. 단계

### 1단계: Pi 기본 설정 (책상에서)

1. OS 설치, 호스트 이름 정하기(예: `pi-a2`), SSH 키 등록.
2. 유선 `eth0`을 고정 주소로 잡는다.
   - 주소: `192.168.124.50/24`, 게이트웨이 없음.
   - 라이다(.20, .21)와 PC2(.162)를 피한다.
   - 게이트웨이를 비우는 이유: 기본 경로가 Wi-Fi 쪽으로 나가야 한다.
3. Wi-Fi를 연구실 공유기에 등록한다. 실외용으로 핫스팟도 미리 등록한다.
4. Tailscale을 설치하고 로그인한다. 이름이 `pi-a2.tailcb6bfb.ts.net`으로 잡히는지 확인한다.
5. mosquitto를 설치하고, pi7 설정을 옮겨 아래처럼 연다.
   ```
   listener 1883 192.168.124.50     # PC2 브리지
   listener 9001                    # 웹 (WebSocket)
   protocol websockets
   allow_anonymous true
   ```
   - 9001은 Tailscale 쪽으로만 열면 충분하다.
   - 방화벽(nftables/ufw)으로 `wlan0`의 9001과 1883을 막는다. `tailscale0`과 `eth0`만 연다.
6. 카메라 중계 `:8090` → `192.168.124.162:8090`을 설정한다.
   - socat 한 줄이나 nginx `stream` 프록시면 된다.
   - systemd 서비스로 등록한다.

**확인:**
- `mosquitto_sub -h localhost -t '#' -v`가 붙는다.
- 다른 PC에서 `ws://pi-a2.tailcb6bfb.ts.net:9001/mqtt`로 접속된다.

### 2단계: 로봇에 연결

1. 노트북 대신 Pi를 항공 커넥터에 꽂는다.
2. Pi에서 `ping 192.168.124.162`가 되는지 확인한다.
3. PC2에서 `ping 192.168.124.50`이 되는지 확인한다.
   - 노트북이 필요하면 Pi를 거쳐 SSH로 들어간다(ProxyJump).
   - 비상용 경로로 노트북 직결도 남겨 둔다.

### 3단계: 브리지를 Pi 브로커로 돌리기

1. PC2의 mosquitto를 끈다(`~/viz_a2/stop.sh`).
2. `run.sh`가 브로커를 띄우지 않게 한다. 예: 환경변수 `A2_BROKER`가 있으면 로컬 브로커를 건너뛴다.
3. 브리지를 다시 띄운다: `python3 a2_bridge.py --broker 192.168.124.50`.
4. 웹 연결 관리에서 `ws://pi-a2.tailcb6bfb.ts.net:9001/mqtt`를 고른다. `presets.ts`에 pi7, pi3와 같은 모양으로 프리셋을 하나 추가한다.

**확인:**
- 카드 `a2-001`이 뜬다.
- 상세 상태판, 로봇 모드, 카메라가 나온다.
- 모의 실행에서 ping, teleop 왕복이 된다.

### 4단계: 자동 시작

| 장비 | 무엇을 | 방법 |
|---|---|---|
| Pi | mosquitto, tailscaled, 카메라 중계 | systemd 서비스, 부팅 시 시작 |
| PC2 | `a2_bridge.py --broker 192.168.124.50` | `crontab @reboot`로 띄운다(sudo 불필요). systemd 사용자 서비스는 `loginctl enable-linger`에 sudo가 필요해 담당자 승인 뒤에만 쓴다 |

**브리지는 늘 모의 실행으로 뜬다.** 그래서 자동 시작해도 로봇이 혼자 움직이지는 않는다. 실제 제어는 사람이 웹에서 고를 때만 켜진다.

**확인:** 로봇과 Pi 전원을 껐다 켠 뒤, 사람이 아무것도 하지 않아도 웹에 카드가 다시 뜬다.

### 5단계: 실외와 무선 점검

1. 실외 핫스팟으로 붙여서 상태와 teleop 지연을 잰다. 키를 누른 뒤 브리지 로그에 `Move`가 찍히기까지 걸리는 시간을 본다.
2. 링크를 일부러 끊어 본다(핫스팟 끄기). 1초 안에 로봇이 서는지 확인한다.
   - 브리지는 MQTT 연결이 끊기면 서게 되어 있다.
   - Pi가 살아 있어도 웹이 끊기면 웹의 유지 신호가 끊긴다. 그래서 `hold_ms`가 지나면 선다.
3. 카메라 대역폭을 확인한다(§5).

## 4. 브리지에서 바꿀 것

| 변경 | 이유 |
|---|---|
| `run.sh`: 브로커 주소를 인자나 환경변수로 받고, 원격 브로커면 로컬 mosquitto를 띄우지 않기 | 3단계 |
| `registration.ip`를 실제 `net1` 주소로 채우기 (지금은 상수) | 진단용 |
| 브로커가 오래 끊기면 로그에 크게 남기기 | Pi 전원, 유선 문제를 바로 알아보려고 |
| (선택) 카메라 해상도 낮추기 | §5 |

웹 쪽은 `presets.ts`에 Pi 프리셋 한 줄만 더한다. 카메라와 명령 경로는 그대로다.

## 5. 카메라 대역폭

- 지금은 1080p JPEG(장당 약 200 KB)를 10 fps로 보낸다. 약 16 Mbps다.
- 유선 직결에서는 충분하지만, Pi Wi-Fi + Tailscale + 핫스팟을 거치면 빠듯하다.
- 1차 대응: `a2_bridge.py --cam-fps 5`(약 8 Mbps). 인자 하나로 바꿀 수 있다.
- 그래도 부족하면 PC2에서 해상도를 줄여 보낸다.
  - 예: 960×540이면 장당 약 1/4.
  - PC2에 인터넷이 없으므로 리사이즈 라이브러리(Pillow 등)를 휠로 `vendor/`에 넣거나, PC2에 이미 있는 OpenCV(ROS 2 Humble)를 쓴다. PC2에서 쓸 수 있는지 먼저 확인한다.
- 보는 화면이 없으면 카메라를 읽지 않는다. 그래서 상세 카메라 탭을 닫으면 대역폭도 0이 된다.

## 6. 위험과 대응

| 위험 | 대응 |
|---|---|
| 12 V 핀을 잘못 연결해 Pi나 동글이 손상됨 | 핀 배치를 확인하기 전에는 보조배터리로 전원을 준다. 변환 케이블은 정품만 쓴다 |
| Wi-Fi가 끊긴 사이 로봇이 계속 움직임 | 웹 유지 신호가 끊기면 `hold_ms`(최대 1초) 뒤 `StopMove`. 5단계 2번에서 실측한다. 조종기 비상정지(L2+B)는 항상 손에 둔다 |
| 브로커가 Pi로 옮겨 가면서 PC2 브리지가 브로커를 못 찾음 | 브리지는 1~5초 간격으로 다시 붙는다. 그동안 teleop은 멈춘 상태다 |
| 같은 브로커에 로봇이 둘이면 명령 대상이 막힘 (`commandTargetFor`) | A2 전용 Pi 브로커를 쓴다. pi7(Go1)과 합치지 않는다 |
| 브로커가 인증 없이 열림 | 9001과 1883은 `tailscale0`과 `eth0`에만 연다. 연구실 Wi-Fi 쪽은 막는다 |
| PC2 시계가 약 8분 느림 | 웹은 받은 시각으로 판단해서 지금은 문제가 없다. 기록을 맞춰야 하면 Pi를 NTP 서버로 두고 PC2가 맞추게 한다(PC2 설정 변경이라 승인 필요) |

## 7. 정할 것

1. Pi 기종과 OS: pi7과 같은 판으로 맞출지.
2. Pi 전원: 보조배터리로 할지, 항공 커넥터 12 V로 할지(핀 배치 확인 필요).
3. 실외 무선: 휴대폰 핫스팟으로 할지, USB LTE 동글과 데이터 쉐어링 유심으로 할지.
   - 로봇의 내장 4G 모듈(`/api/fourg_agent`)이 PC2나 Pi에 인터넷을 주는지는 아직 확인하지 않았다.
4. Tailscale 이름(`pi-a2` 등)과 웹 프리셋 이름.
5. `a2-bridge/`를 저장소에 올릴지. `.gitignore`에 `!/a2-bridge/`를 더해야 한다.
