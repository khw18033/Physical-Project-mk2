# 작업 보고: 추론 영상 위 탐지 영역 · 객체 재식별 층 — 버튼은 한 자리에 쌓는다

**날짜**: 2026-11-23 (버튼 자리는 2026-11-24)
**커밋**: `976a830`(영역 · 재식별 층 · 근거 카드 영어) · `5b427ce`(그중 `VisionToolStack` 부분) — 브랜치 `khw_VZ`
**상태**: **가시화 쪽 코드는 끝났다.** 실서버(data_stream)에 붙여 영역 · 재식별이 도는 것을 본 기록은 커밋에 없다 — 6절.
**작성**: 2026-11-24 — 작업 뒤에 커밋 기록 · 코드에서 다시 정리한 보고서

> 한 줄 요약 — 객체 탐지 추론 영상(확대 화면) 위에 두 층을 얹었다. 「영역 지정」으로 영상을 끌어 탐지 영역을 정하면 data_stream `/control/roi` 에,
> 「재식별 선택」으로 상자를 누르면 `/control/reid` 에 보낸다. 이 화면은 **고르고 보여 주기만** 하고 실제 처리는 data_stream 이 한다.
> 근거 카드는 data_stream 카드와 같이 영어로만 쓴다. 다음 날, 두 층의 버튼이 2열 칸에서 8px 로 눌려 겹치던 것을 한 자리에 쌓아 고쳤다.

## 1절 — 무엇을 바꿨나

### 탐지 영역 층 — `VisionRoi.tsx`(신설)

- 「영역 지정」을 누르면 켜지고, 영상 위를 끌면 색(청록)으로 영역이 그려지며 data_stream 에 보낸다. 영역마다 ✕ 로 그것만 지우고, 「영역 취소」로 모두 지운다.
- 창구 `<base>/control/roi` — GET 지금 영역 · POST 바꾸기 · DELETE 지우기. 좌표는 프레임 대비 0~1 비율. 전부 지우면 DELETE, 아니면 `{ rects, model: null }` 을 POST.
- 영역의 주인은 data_stream 이다. 비전이 그 안만 탐지하고 개수도 그 안에서 센다(커밋 · 주석). 이 층은 2초마다 영역을 다시 읽으므로 다른 화면(`/vision/view`)에서 바꾼 영역도 여기 보인다.
- 너무 작은 끌기(가로나 세로가 0.01 미만)는 보내지 않는다. 한 영역을 그리면 지정 모드가 꺼진다.
- `overlay_prefs.roi` 가 거짓인 모델에는 층을 세우지 않는다. 지정 모드가 아니면 층이 마우스를 받지 않아 카드 층의 마우스 · 클릭이 그대로 움직인다.

### 객체 재식별 층 — `VisionReid.tsx`(신설)

- 「재식별 선택」을 누르고 물체 상자를 클릭하면 그 물체를 `/control/reid` 에 POST 한다(`model` · `bbox` · `track_id` · `n` · `label`). 겹친 상자가 여럿이면 가장 작은 것을 고른다. 「재식별 취소」는 DELETE.
- 따라가기 · 다시 찾기 · 다른 카메라 연결은 data_stream `vision/reid.py` 가 하고, 찾은 물체는 서버가 영상에 자홍색 `REID <번호>` 로 그린다. 그래서 이 층은 다시 그리지 않는다.
- 1초마다 검출(누를 상자)과 고른 물체 목록을 읽고, 버튼 아래에 `REID <번호> <이름> · 본 카메라 → …` 를 적는다.
- `overlay_prefs.reid`(비전 기능 「객체 재식별」)가 거짓이면 층을 세우지 않는다.

### 그 밖 (`976a830`)

- `VisionViews.tsx`: 두 층을 카드 층 옆에 — 확대 스트림(`RecordFrame`) 안, 모델이 있을 때만.
- `VisionCards.tsx`: 사전에 없는 클래스(지정 클래스 직접 입력)는 키 대신 이름 그대로 보인다.
- i18n: 근거 카드 문구를 한국어 사전에서도 영어로(data_stream 카드와 같다). 새 근거 이름(`dict_features` · `colour` · `ovd_agree` · `clip_shape` · `size_veto` 등)과 클래스(`person` · `door` · `chair` · `desk` · `demo_door` · `demo_box`), 영역 · 재식별 버튼 문구.
- `style.css`: `vroi-*` · `vreid-*`.

## 2절 — 버튼 자리 — `VisionToolStack.tsx`(`5b427ce` 신설)

**문제.** 하드웨어 카드에서 영상이 둘 이상이면 재식별 버튼이 세로로 길게 겹쳤다. 두 층의 버튼 줄이 제각기 `left = 그림 오른쪽 끝 − 8px` 에 절대 위치로 서서 `translateX(-100%)` 로 왼쪽으로 밀었는데,
절대 위치 상자는 폭을 안 주면 「담는 칸 폭 − left」 안에서만 넓어진다. 영상이 하나면 좌우 여백이 남아 괜찮았지만, 2열 격자에서는 그림이 칸 폭을 꽉 채워 **남는 폭이 8px** 가 됐다.
버튼 글이 한 글자씩 줄바꿈해 세로로 길어지고, 고정 간격(8 / 40px)으로 선 두 묶음이 서로 겹쳤다.

**고친 것.**

- 자리를 **오른쪽 기준(`right`)** 으로 하나만 세운다(`vtool-stack`, 그림 오른쪽 위 · 결과 띠 아래 8px). 두 층은 제 버튼 줄을 `createPortal` 로 이 자리에 넣는다 — 영역 줄 아래에 재식별 줄.
- 한쪽 줄의 높이가 바뀌어도 다른 줄이 아래로 밀릴 뿐 겹치지 않는다. 버튼은 `white-space:nowrap`, 재식별 항목 · 오류 글은 한 줄로 자르고 전체는 `title` 로 둔다.
- 결과 띠 높이(`bandPx`)는 프레임 크기를 아는 두 층이 `onBand` 로 알려 준다. 재식별 층도 알리므로 영역 층을 끈 모델에서도 띠 아래에 선다.
- 자리가 아직 없으면(칸이 막 선 첫 그림) 버튼을 안 그린다. 그림이 없을 때도 자리 `div` 는 `hidden` 으로 남겨 포털할 곳이 사라져 깜빡이는 것을 막는다.

## 6절 — 한계 · 남은 것

- **실서버 확인.** data_stream `/control/roi` · `/control/reid` 에 실제로 붙여 영역 안만 탐지되는지, `REID` 상자가 다른 카메라로 이어지는지 본 기록이 커밋에 없다.
- 이 층들은 확대 스트림 칸(`RecordFrame` 안)에만 선다. 접힌 카드의 한 장(`Still`)에는 없다.
- 영역은 `model: null` 로 보낸다 — 모델별로 다른 영역을 주는 길은 화면에 없다.
- 조회 주기가 층마다 다르다(영역 2초 · 재식별 1초). 서버가 잠시 없으면 마지막 값을 그대로 둔다.
- `contentBox` 가 네 파일에 같은 식으로 복사돼 있다. 셈을 바꾸면 넷을 같이 고쳐야 한다.
- 영역 · 재식별 버튼 문구는 한국어 화면에서 한국어지만, 근거 카드는 언어와 상관없이 영어다.
