5. 정상 동작 확인 — 다섯 곳이 이어져야 함

| 위치 | 떠야 하는 것 |
|---|---|
| PC 촬영 | `촬영 #N 완료` → `[worker] stitched` → `✅ uploaded` |
| 서버 `pano.log` | `[pano] saved: .../equirect.jpg (~3200KB)` |
| 서버 live | `[live] #N ... 전송 N개 ... UDP OK` |
| PC 브릿지 | `NEW ts=...` (타임스탬프가 바뀜) |
| 유니티 | `[Anchor360] RX:` + `Anchor360_Obstacles` 아래 큐브 |

**브릿지의 `ts`와 유니티 `RX`의 `timestamp`가 같으면 관통 확인.**

7. 자주 걸리는 것

| 증상 | 원인 | 조치 |
|---|---|---|
| 브릿지 `연결 거부 (10061)` | `pano_receiver`가 꺼져 있음 | 2-1 먼저 |
| `camera connect failed` | 카메라 IP 변경 / Farsight 미연결 | 1-1, 1-2 |
| 첫 stitch 25초 | TRT 엔진 콜드 스타트 | 2장째부터 12~19초로 정상화 |
| `⚠️ 큐 N개 적체` | stitch가 촬영을 못 따라감 | `--interval 30` 또는 `--topfixer 0` |
| 유니티에 큐브 안 뜸 | 브릿지 `NEW`는 뜨는데 `RX` 없으면 방화벽 | UDP 5010 인바운드 허용 |
| 새 사진 1장 놓침 | live를 촬영보다 늦게 띄움 | 2-2 → 3-2 순서 |
