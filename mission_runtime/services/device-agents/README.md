# 장치 에이전트

말단 장치에서 도는 경량 에이전트. 센서 취득과 상위 전송만 하고, 브로커·수집기·
오케스트레이터 제어면을 설치하지 않는다(AI-B-10).

| 디렉터리 | 장치 |
|---|---|
| `drone-pi4/` | Raspberry Pi 4 급 컴패니언 — 카메라 취득·전송·온디바이스 후보 제안 |

새 장치를 더할 때 이 디렉터리에 하위 폴더를 하나 만든다. 공통 계약은
`mission_runtime` 패키지에서 가져오고, 장치별 차이는 그 폴더 안에만 둔다.

이미지·캡처 데이터는 두지 않는다 — 공개 트리 밖(`local/`)이다.
