# services/ — 런타임을 쓰는 실행 단위

`mission_runtime` 패키지는 라이브러리다. 이 디렉터리에는 그 라이브러리를 **실제로
띄우는 쪽**이 들어 있다. 패키지가 이들을 import 하지 않는다 — 방향은 한쪽이다.

| 디렉터리 | 무엇 | 어디서 도나 |
|---|---|---|
| `edge-node/` | 구역 엣지 서비스 — 후처리·합의·추적·보존 | 구역 엣지 1대 |
| `device-agents/drone-pi4/` | 장치 에이전트 — 카메라 취득과 상위 전송 | 말단 장치 |

## 왜 패키지 밖인가

말단과 엣지가 설치하는 것이 서로 다르다(AI-B-10: 말단에 서버형 미들웨어를 두지
않는다). 둘을 패키지 안에 넣으면 한쪽만 필요한 기계가 양쪽 의존성을 받는다. 그래서
실행 단위는 밖에 두고 공통 계약만 패키지에서 가져간다.

캡처한 데이터·가중치는 이 디렉터리에 두지 않는다 — 공개 트리 밖(`local/`)이다.
