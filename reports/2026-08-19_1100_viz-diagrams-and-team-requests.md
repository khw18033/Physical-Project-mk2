## 3. Dear PyGui 예시와의 비교

교수님 참고자료인 [Image-Processing-Node-Editor](https://github.com/Kazuhito00/Image-Processing-Node-Editor)(Kazuhito00)를 확인했다. **같은 계열이 맞고, IPNE는 F4 + F10 + F5를 이미지 도메인 하나로 좁힌 부분집합에 가깝다.**

| IPNE | 대응 요구사항 |
|---|---|
| 노드를 연결해 처리 경로 조립 | 해석 파이프라인 + 노드 조합 편집기 |
| 타입이 맞는 포트끼리만 연결 | 연결 유효성 강제 · 편집 중 실시간 검증 |
| 노드마다 결과 실시간 표시 | 부분 실행 및 중간 결과 확인 · 역방향 관측 |
| 그래프 JSON export/import | 계약과의 무손실 왕복 |
| `node/` 디렉토리 모듈 추가로 확장 | 노드 카탈로그 자동 구성 · 코어 무변경 확장 |
| Deep Learning 노드 | 오브젝트 디텍션을 transform 노드로 호출 |

타입 검증은 오히려 이쪽이 더 엄격하다. IPNE는 포트 타입 일치 정도인데, 우리는 디스크립터·렌더러·파이프라인 **세 계약 사이의 참조 무결성**까지 검사한다.

**IPNE에 대응 개념이 없는 것**: 자동 프로비저닝(F2), 선언형 디스크립터(F1), 공간·추상화 계층(F3·F11), 제어 명령 발행과 감사 기록(F9), LLM·음성(F12·F13), server/client 실행 위치 분기, 관측 스택 연동. 특히 **F2가 프로젝트의 1번 목적인데 IPNE에는 아예 없다.** IPNE는 "사람이 조립하는 도구"고, 이쪽은 "자동으로 생기고 + 사람이 조립도 하는 것"이다.

**요건에 명시가 약해 챙겨야 할 3가지** (이번 비교에서 도출):

1. **노드 안에 결과가 인라인으로 뜨는 표현 형태.** 부분 실행·역방향 관측으로 요건은 있으나 "노드 박스 안에 미리보기"라는 UI 형태는 문서에 없다. 요건을 충족하면서도 밋밋한 구현이 나올 수 있는 자리다.
2. **노드 팔레트의 분류 축.** `kind` 는 source/transform/sink 3개뿐인데 이건 실행 계약이지 사용자가 고르는 분류가 아니다. 노드 카탈로그를 "자동 구성"한다고만 하고 무슨 기준으로 묶을지가 없다.
3. **즉시성과 반영 절차의 분리.** IPNE는 연결하는 순간 결과가 바뀐다. 우리는 시험 실행 → 명시적 반영을 분리했고 관제 시스템이니 이게 맞다. 다만 **반영은 명시적, 미리보기는 즉시**로 두 개를 갈라두어야 데모에서 같은 인상이 난다.

**DearPyGui를 쓸 필요는 없다.** NFR-007에 "설정 명세는 특정 편집기 구현(데스크톱/웹)에 의존하지 않는 독립 포맷"이라고 이미 못 박혀 있고, 현재 프로토타입도 웹이다. 예시와 같은 계열이되 명세와 편집기를 분리했다는 설명의 근거가 그대로 NFR-007이다.

| 화면 | 시각화한 요건 |
|---|---|
| L0 노드 편집기 | 인라인 미리보기(REQ-406·1007), 타입 불일치 차단(REQ-1004·804), LLM 제안 상태(REQ-1204), 시험 실행/반영 분리(REQ-1006), 실행 위치 분기(REQ-404) |

### 순서도 연계 화면(L0b)을 따로 만든 이유

L0 화면은 요구사항을 잘 보여주지만 캡스톤 시스템과의 접점이 없다. 순서도의 블록을 그대로 노드로 옮기면 "이 프레임워크가 우리 캡스톤에 어떻게 얹히는지"가 설명 없이 보인다.

구역 프레임 3개(구역 1 / 구역 2 / 원격 서버)로 묶고, 순서도 블록 ↔ 노드 종류 대응표를 좌측 패널에 넣었다. 순서도의 "제어 노드 (구역 N)"이 **가시화의 Node 계층에 그대로 대응**한다는 것이 이 그림의 핵심이다.

제어 명령은 노란 점선으로 오른쪽에서 왼쪽으로 되돌아가게 그렸다. 순서도의 관리자 → Unity → 제어 노드 화살표에 대응하며, 데이터 간선과 색·방향을 달리해 **그래프 비순환 검증에서 제외되는 경로**임을 표시했다.

### 이 그림이 드러낸 것

**좌표계 미확정(H-2)의 비용이 그림으로 보인다.** L0b의 Unity 노드에서 구역 2 가상 맵이 점선 빈 박스로 남아 있고, 제어 노드 1 안에는 빨간 `site_id 필요 ★H-1` / `site-1 로컬 ★H-2` 가 붙어 있다. 좌표계 기준이 없으면 두 구역을 한 맵에 겹칠 수 없다는 것을 말로 설명하는 것보다 빠르다.

8. **협의 항목 회신 대기 유지.** `D-1`, `I-2`, `H-1`, `H-2` 는 여전히 미확정이며 L0b 화면에 그대로 표시되어 있다.
