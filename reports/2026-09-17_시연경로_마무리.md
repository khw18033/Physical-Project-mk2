## 3. §2 — 규칙을 어떻게 갈랐나 (5단계가 그대로 쓴다)

### 사각의 정체

```js
/>([^<>{}]*[가-힣][^<>]*)</g
//  ^^^^^^^^ 여는 쪽이 중괄호를 배제한다
```

`<small>{items.length}판</small>` 은 `>` 와 한글 사이에 `{` 가 있어 **매칭 후보가 되지도
못했다.** 그래서 2단계가 「0건」이라 적고도 9건이 살아 있었다.

### 잣대 둘을 섞었다 — **하나로는 두 번 다 뚫렸다**

표현식을 안쪽부터 `{}` 로 접으면 보간식 옆 텍스트가 보인다. 그 다음이 문제였다.

| 잣대 | 무엇을 버리나 | 혼자 쓰면 |
|---|---|---|
| **① 닫는 `<` 가 태그 시작인가** (`/` 이거나 글자) | `a > 1 ? 이름 : 0 < 2` — `<` 다음이 공백 | `= 0; const x1 = …` 가 **샌다** (우연히 `<` 뒤가 글자) |
| **② 잡힌 텍스트에 코드 문법이 없는가** (`;` `=>` `const ` `return ` `&&` …) | `= 0; const x1 = …` | `(a) => a > 1 ? 이름 : 0 < 2` 가 **샌다** (`=>` 가 잡힌 범위 밖) |

**둘 다 대조군이 잡았다.** ②만 썼을 때 화살표 함수 대조군이 실패했고, ①만 썼을 때
실물 오탐 둘이 되돌아왔다.

### ②를 **잡힌 텍스트에만** 건다 — 줄 전체가 아니다

```tsx
return <p>3판</p>;
```

줄에 `;` 가 있지만 **진짜 텍스트 노드**다. 줄 전체에 ②를 걸면 이것이 샌다. 텍스트 노드
안에는 `;` 도 `const ` 도 안 나오므로 잡힌 범위에만 거는 것이 맞다. 대조군에 넣어 못박았다.

> **5단계 `verify:no-raw-korean` 에 그대로 넘긴다.** 저장소 전체로 넓히면 코드가 훨씬
> 다양해지므로 ①·② 를 둘 다 들고 가야 하고, ② 를 줄 단위로 옮기면 오탐이 난다.

## 4. §3 — `useLang()` 을 컴포넌트 단위로

파일에 `useLang()` 이 **한 번이라도** 있으면 통과하던 것을, `function [A-Z]…` 경계로 잘라
**컴포넌트마다** 본다. 지금 시연 경로에서 `t()` 를 쓰는 컴포넌트가 **33개**이고 전부 갖고 있다.

소문자 함수(`producerWord` · `mockSteps`)에서 `t()` 를 부르는 것은 대상이 아니다 —
그리는 컴포넌트가 가지면 된다. 대조군에 그 경우를 넣었다.

### 대조군이 실물에서 잡는 것을 확인했다

`MissionHistory.tsx` 의 **둘째 컴포넌트** `RunLine` 에서 `useLang()` 을 빼고 돌렸다.

```
❌ views/MissionHistory.tsx: RunLine() 가 t() 를 쓰는데 useLang() 이 없다 —
   언어를 바꿔도 이 부품만 옛 언어로 남는다
```

첫 컴포넌트(`MissionHistoryList`)는 훅을 그대로 갖고 있었으므로 **파일 단위 검사였다면
통과했을 자리**다. 조인 것이 맞다.

### ★ 그 시험이 중복을 하나 찾았다

처음 시험했을 때 **안 잡혔다.** 파 보니 `RunLine` 에 `useLang()` 이 **두 번** 들어가 있었다 —
2단계에서 훅을 기계로 넣을 때 두 규칙(`function [A-Z]…` 과 `}) {`)에 같은 자리가 걸려
겹쳐 넣은 것이다. 하나를 지우니 대조군이 잡았다.

**기능에는 문제가 없었다**(같은 훅을 두 번 부르는 것은 무해하다). 다만 **대조군을 무력화하고
있었고**, 그것을 시험이 아니었으면 몰랐다.

## 5. 되돌림 시험

```

```

**잡았다.** 되돌린 뒤 복원했다.

```

✅ useLang() — t() 를 쓰는 컴포넌트 33개가 **하나씩** 전부 갖고 있다 (파일 단위가 아니다)
✅ 사전 — ko 533키 · en 532키 · 비어 있는 것은 mode.mock 하나뿐
✅ 자리표시 20건 · 요구사항 제목이 전부 사전에 있고 id 가 안 겹친다
✅ 대조군 13건 — 박힌 한글은 잡고, 주석과 키는 통과시킨다
```

대조군을 **4건 → 13건**으로 늘렸다. 새로 든 것 아홉 중 이번에 값을 한 것들:

| 대조군 | 무엇을 막나 |
|---|---|
| 보간식 옆 단위 (`{}판`) | **이번에 뚫린 모양이 다시 뚫리는 것** |
| 보간식 사이 연결어 (`{a}/{b} 노드`) | 같은 모양의 변형 |
| 여러 줄 JSX 의 보간식 옆 단위 | 줄바꿈으로 막으면 놓치는 자리 |
| 비교 연산자·화살표 함수가 든 줄 | 오탐 |
| **세미콜론이 붙은 진짜 JSX** | ②를 줄 단위로 옮기면 나는 오탐 |
| **둘째 컴포넌트에서 훅을 뺀 사본** | §3 의 핵심 |
| 소문자 순수 함수의 `t()` | 오탐 |

## 8. 지시서와 다르게 한 곳 — 둘

### ① 순서를 뒤집었다 — 검사를 먼저 고쳤다

지시서는 §1(9건) → §2(검사)로 적었는데 **§2 를 먼저 했다.** 검사가 먼저 서야 「고쳤다」를
검사가 말해 준다 — 9건을 먼저 끄면 무엇을 고쳤는지 확인할 방법이 그 순간에는 없다.
실제로 검사를 고치자 9건이 정확히 빨갛게 떴고, 그 목록이 지시서와 같은지 대조할 수 있었다.

### ② `useLang()` 중복 하나를 지웠다 (§4 ★)

지시서에 없던 일이다. 대조군 시험이 그것 때문에 실패해서 발견했다. 기능에는 문제가 없었으나
**대조군을 무력화하고 있었다.**
