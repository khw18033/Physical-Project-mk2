## 계약 재사용

새 그래프 형식을 만들지 않고 기존 `pipeline.schema.json`의 다음 구조를 사용했다.

- 노드 종류: `source` · `transform` · `sink`
- 실행 위치: `server` · `client`
- 비순환 `edges[]`
- source 1개 이상, sink 1개 이상
- 편집 초안과 운영 그래프 버전 분리

현 단계 카탈로그는 7종이다.

| 종류 | 노드 |
|---|---|
| source | Prometheus 시계열, 카메라 스트림 |
| transform | 재표본화, 구간 집계 |
| sink | 그래프, 표, 영상 렌더러 |

카탈로그는 목 게이트웨이에서 내려오며 UI에 엔진별 분기나 고정 노드 버튼을 만들지
않았다. 실제 백엔드 카탈로그가 정해지면 HTTP 어댑터만 교체할 수 있다.

## 편집과 검증

화면에서 카탈로그 노드를 추가하고 캔버스 위에 드래그해 배치한다. 출력 노드와 입력
노드를 차례로 선택해 연결하며, 명백한 타입 불일치는 화면에서 먼저 막는다. 최종 방어선은
서버 검증기다.

서버는 다음을 검사한다.

1. 중복·존재하지 않는 노드 식별자
2. source 부재 또는 sink 부재
3. 출력/입력 타입 불일치
4. sink에서 나가거나 source로 들어가는 역방향 연결
5. 순환 그래프
6. 입력 또는 출력이 없는 고립 노드

시험 실행은 노드별 처리 행 수·소요 시간과 성공 여부를 반환한다. 현재는 목 실행기지만
각 노드 결과를 따로 보여 주므로 실제 F8 실행기로 교체할 접점이 분리돼 있다.

## 반영과 되돌리기

| 상태 | 의미 |
|---|---|
| draft | 화면에서 편집 중인 초안. 운영에 영향 없음 |
| tested | 현재 초안이 서버 시험 실행을 통과하고 토큰을 받은 상태 |
| active | 명시적 반영을 거친 운영 그래프 |
| previous | 직전 운영 그래프. 되돌리기 대상 |

잘못된 토큰이나 다른 초안으로 반영하면 HTTP 409로 거부한다. 반영과 되돌리기는
행위·그래프 id·버전·조작자·서버 시각을 감사 배열에 남긴다. 실제 감사 저장소 연결은
백엔드 O-5 계약 확정 뒤 이 경로를 교체해야 한다.

## 남은 경계

- `VZ-L-04`: LLM이 만드는 것은 **운영 그래프가 아니라 초안**이다. 계약 확정 후 현재
  draft 입력 앞에 연결하며 시험·반영 절차를 우회할 수 없다.
- 실제 노드 카탈로그와 실행기는 백엔드 소유 계약이 아직 없으므로 목 구현이다.
- 반영/되돌리기 감사는 현재 서버 메모리에만 남는다. 운영 감사 저장은 O-5 계약이 필요하다.
- 그래프는 서버 프로세스 메모리에 있어 재기동 시 사라진다. 영속 저장소는 실제 백엔드
  연동 단계에서 결정한다.
