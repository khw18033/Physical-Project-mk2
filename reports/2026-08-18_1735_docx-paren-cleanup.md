# 2026-08-18 17:35 — 가시화 담당 요구사항 정의서 괄호 정리

## 요청

`가시화 담당 요구사항 정의서.docx`의 불필요한 괄호를 제거한다. 해당 파일만 대상.

## 경위

처음에 대상 범위를 `구현계획서.md`까지로 잘못 잡아 정리를 적용했다가, 지적을 받고
`git checkout`으로 되돌렸다. 커밋 전이었으므로 커밋본은 영향 없음. 이번 변경은
docx 한 파일에만 적용했다.

## 사용자 편집 보존

작업 전 확인 결과 docx가 커밋본과 달랐다. 워드에서 열어 **상대 파트 이름을
"강대규" → "이대규"로 수정**한 상태였다. 재생성 시 이 편집이 되돌아가므로,
생성 스크립트의 이름을 먼저 고친 뒤 빌드했다. 문단 수 339개 동일, 이름 유지 확인.

## 정리 규칙

| 원래 형태 | 바꾼 형태 |
|---|---|
| 동격 설명 `이대규 (OpenTelemetry 기반…)` | 줄표 — `이대규 — OpenTelemetry 기반…` |
| 열거 후보 `(OTel / Prometheus / Grafana)` | 가운뎃점 `OTel·Prometheus·Grafana` |
| 부연 `허용 (샘플링·배치 전송이 전제)` | 마침표로 분리 `허용. 샘플링·배치 전송이 전제` |
| 교차 참조 `(D-2)` | 화살표 `→ D-2` 또는 `4장 D-2 참조` |
| JSON 주석 `"string (UUID)"` | 쉼표 `"string, UUID"` |
| 조건 `"(origin.path=voice일 때 필수)"` | 줄표 `— origin.path=voice일 때 필수` |
| 불필요한 병기 `질의(pull)와 발행(push)`, `안(案)` | 삭제 |
| 장 제목 `2. 받아야 하는 것 (수신부: …)` | 줄표 `2. 받아야 하는 것 — 수신부: …` |
