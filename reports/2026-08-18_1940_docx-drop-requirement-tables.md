# 2026-08-18 19:40 — 요구사항 표 제거, 코드 참조를 이름으로 교체

## 요청

요구사항 표는 별도 문서가 있으니 따로 보는 편이 낫다. 표를 빼고, 요구사항 코드로
참조된 부분도 이름으로 바꾼다.

## 판단

두 요청은 한 몸이다. **표를 빼면 REQ-1104 같은 코드가 문서 안에서 해석 불가능해진다.**
읽는 사람이 코드를 보고 다른 문서를 열어 찾아봐야 하는데, 그 수고를 시키려고 표를 뺀 것이
아니다. 그래서 코드를 전부 이름으로 바꿨다.

표의 "대응 요구사항" 열을 "관련 요구사항"으로 바꾸고 값을 이름으로 채웠다.

산문 안의 코드도 같이 풀었다.

- "REQ-1104는 상위 지표에 대해..." → "가시화 요구사항은 상위 지표에 대해..."
- "NFR-011은 본래 LLM 한정 요건이고" → "관측 사실과 생성 내용을 구별하라는 요건은 본래 LLM 한정이고"
- "가시화의 REQ-903 낙관적 반영 대 확인 후 반영" → "가시화의 낙관적 반영 대 확인 후 반영"
- "F4 파이프라인의 transform 노드" → "해석 파이프라인의 transform 노드"
- "F12 로컬 LLM 계층과 예측 AI의 경계" → "로컬 LLM 계층과 예측 AI의 경계"

I-·O-·D-·A-·H- 기호는 그대로 두었다. **이 문서 안에서 정의되고 이 문서 안에서만 쓰이므로
자기완결적이다.** 반면 REQ·NFR·F는 외부 문서를 봐야 풀리는 코드라 바꿨다.
