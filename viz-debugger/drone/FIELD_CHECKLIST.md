- [ ] QGC 파라미터 `EKF2_GPS_POS_X / Y / Z` 에 GPS 안테나 값을 넣고 재부팅했다

## 2. 현장 설치

- [ ] RTK 베이스: 하늘이 트인 곳 · 삼각대 고정 · 서베이 완료(위치 고정) 확인
- [ ] 노트북 핫스팟 켜기 → Pi 5 · 노트북이 같은 망 (Pi IP ________)
- [ ] 노트북 `sar-laptop.bat` 실행 → 창 2개(RTK 베이스 → Pi / SAR 미러) 확인
- [ ] 화면 열기 → ⇄ 연결 관리: 드론 데이터 서버 `http://127.0.0.1:8766`
- [ ] 리플렉터 배치: 드론(RTK Fixed)을 리플렉터 옆에 두고 「드론 위치를 리플렉터로」 — 위성 사진 클릭보다 정확. 전부 **✓ 보인다** (관측 띠 가운데 · 선 끝에서 개구 절반 이상 안쪽)
- [ ] 리플렉터를 레이더 쪽(오른쪽/왼쪽)으로 향하게 세웠다 · 주변에 큰 반사체 없음

## 3. 이륙 전 (화면 「SAR 패스」 1단계가 전부 ✓)

QGroundControl 도 같이 켠다 — 펌웨어 · 캘리브레이션 · 페일세이프 · 비상 모드 변경은 QGC, SAR 임무 · 캡처 · 데이터는 우리 화면.

- [ ] QGC: 시동 전 점검 통과 · 페일세이프(RC 끊김 · 배터리) · `GF_ACTION` 2(Hold) 이상
- [ ] 상태판 **Pi** 칩 초록 (온도 · 스로틀링 · 전압 · 디스크) — 빨강이면 패스 시작이 막힌다
- [ ] 「패스 동안 지오펜스」 켬 (계획 → 비행 조건, 기본 켬)

- [ ] RTK **Fixed** · 보정 수신 중 (상태판 RTK · 「보정 수신」)
- [ ] 시계 오차(파이 − FC GPS) ±0.1 s 안 — 아니면 `sudo python -m sar_pass timesync --apply`
- [ ] 레이더 서비스(cansar) 동작 · CAP_ACK 응답 (점검 「레이더 확인」)
- [ ] 데이터 서버 · 디스크 여유 (점검 「데이터 서버」)
- [ ] 바람 → 빔 카드가 초록 또는 노랑 (빨강이면 기다린다) · 배터리 예산 초록
- [ ] 진동 X·Y·Z 30 m/s² 아래 (상태판 「진동」) — 레이더를 단 뒤 처음이면 호버로 먼저 확인
- [ ] 레이더 켠 상태에서 GPS 위성 수 · RTK 가 떨어지지 않는다 — `python -m sar_pass emi --cycles 4 --period 30 --out emi.json` (지상, 날지 않음) 이 「간섭 의심 없음」

## 4. 비행

- [ ] 조종기로 20 m 이륙 · 호버 안정
- [ ] 화면 「시작」 → 「현장 안전 확인」 체크 → **패스 시작**
- [ ] 지도의 빔(청록)이 리플렉터를 지나며 리플렉터가 **빛나는지** 본다
- [ ] 캡처 중 빨간 불 · 패스마다 유효/무효 확인. 무효면 드론이 알아서 다시 난다(최대 재시도)
- [ ] 이상하면: 화면 **중단** 또는 조종기로 모드 전환(CAP_ON 은 그 자리에서 꺼진다)
- [ ] 끝나면 조종기로 착륙 · 시동 끄기

## 5. 착륙 후 (현장을 떠나기 전에)

- [ ] 화면 「비행 데이터」: 패스마다 레이더 파일 개수 · 크기가 0 이 아니다
- [ ] **영상 완료 · 리플렉터 n/n** — 리플렉터가 「찍힘」인가. 안 찍혔으면 「자세히 보기 · 재생」으로 빔이 지나갔는지 본다
- [ ] 빠른 확인: 거리-시간 곡선이 점선과 겹친다 · 레이더 시각 오프셋 ____ ms (리플렉터끼리 2 ms 안)

- [ ] 「전부 받기 (ZIP)」 노트북에 저장 · 다른 저장장치에 한 번 더 복사

## 문제가 생기면

| 증상 | 먼저 볼 곳 |
|---|---|
| 「패스 시작」이 회색 | 점검 「SAR 명령 지원」 — 드론 에이전트 연동 안 됨 → Pi 에서 `python -m sar_pass run …` 로 직접 |
| RTK 가 Fixed 가 안 됨 | 「RTK 상태」 노드 · 노트북 RTK 창 · 베이스 서베이 완료 여부 |
| 기록 시작이 늦다(무효) | 정상 — 다음 패스는 가속 구간을 자동으로 늘린다 |
| 리플렉터가 「안 보임」 | 계획 판정(✓ 보인다였나) → 자세히 보기의 빔 → 거리-시간 곡선 → 시각 오프셋 순서로 |
| 영상이 안 만들어짐 | 화면 아래 「SAR 영상 만들기」 안내(빠진 설정) · 노트북 미러 창의 오류 |
| 화면이 안 바뀜 | ⇄ 연결 관리 주소 · 핫스팟 연결 · Pi `sudo ./install.sh --status` |
