## 1. 배경 — 왜 이 일을 하나

- MK2 는 원래 **로봇 → 엣지 노트북 → 원격 서버** 였다. 원격 서버에 Kafka · TimescaleDB · MySQL · 서버 Prometheus · Loki · Tempo · Grafana · **임무 이력 서버(`8850`)** 가 있다.
- **2026-11-25 작전 변경(사용자):** **로봇 → 노트북.** 노트북이 서버 역할도 한다. 원격 서버는 그대로 둔다(지우거나 끄지 않는다).
- 이 문서의 범위는 그 첫 단계 — **임무 이력 서버를 노트북에 세우고, 노트북에 무엇이 실제로 쌓이는지 로봇을 켜고 시험**하는 것이다.
- 임무 이력 서버는 2026-11-19 원격 서버에 세웠다 — VZ 요청서 `임무이력서버_요청_VZ_261119.md` 대로 · 적합성 검사 44/44 · VZ 가 기존 판 136개를 올렸다. 매일 22:00(KST) 백업 · 최근 30일 보관. **같은 프로그램 · 같은 표를 노트북에 그대로 올린다.**
- **이 문서의 범위 밖:** 업무 데이터(로봇 상태 원본)를 노트북 DB 에 쌓는 것(L3 — 아직 정하지 않았다) · 영상(DS 의 일) · 파이(라즈베리파이) 변경(하지 않는다).
  그래서 시험에서 **「노트북에 쌓이는 것」은 셋**이다 — ① 엣지 Prometheus 의 장치 판정 지표 ② 임무 이력 DB · 그림 ③ DS 가 자기 자리에 쌓는 것(DS 담당이 본다).

## 14. 단계 8 — 전원: 덮개를 닫아도 잠들지 않게 (L4 「잠들지 않게」 · Windows 설정 변경 — **바꾸기 전에 사용자에게 묻는다**)

지금 덮개 닫기 = 충전 · 배터리 둘 다 **「절전」** → 덮개를 닫으면 노트북이 잠들고 WSL · 임무 이력 · 엣지 스택이 멈춘다.

- 권장: 둘 다 **「아무 것도 안 함」**. 다른 길: 「전원 사용」 만 「아무 것도 안 함」(배터리일 때는 지금처럼 잠듦) · 또는 바꾸지 않고 덮개를 연 채로 쓴다.
- ⚠ 「아무 것도 안 함」 이면 **덮개를 닫고 가방에 넣어도 돈다**(열 · 배터리) — 들고 옮길 때는 시작 → 전원 → **시스템 종료**.

바꾸는 곳(사람): **제어판 → 하드웨어 및 소리 → 전원 옵션 → 왼쪽 「덮개를 닫으면 수행되는 작업 선택」** → 「덮개를 닫을 때」 의 「배터리 사용」 · 「전원 사용」 → 고른 값 → **「변경 내용 저장」**.

확인 — Windows PowerShell:

```powershell
powercfg /qh SCHEME_CURRENT SUB_BUTTONS LIDACTION 2>&1 | Tee-Object -FilePath "C:\mk2_edge\logs\mh_8_lid_$(Get-Date -Format yyMMdd_HHmm).txt"
```

**판정:** 「아무 것도 안 함」 으로 바꾼 칸이 `0x00000000`(AC = 전원 사용 · DC = 배터리 사용 · 「절전」 은 `0x00000001`). 그다음 **덮개를 닫고 1분 뒤 열어** — 다른 tailnet 기기에서 health 가 그동안 답했는지(T2 와 같이 본다).

## 21. 이 방의 규칙 — 사용자가 정해 둔 것

- **한국어로 답한다.** 약자(L1 · T4 · E8 …)를 쓸 때는 무엇인지 풀어 쓴다.
- **이 문서를 처음부터 끝까지 읽고 시작한다.** 대화가 길어져 압축되면 요약만 보지 말고 이 문서로 돌아온다.
- **사실을 다 받기 전에 해법을 내지 않는다** — 결과 파일을 보고 판단한다. **문서와 현실이 다르면 먼저 보고하고 결정을 받는다.**
- 사용자가 정한 값은 **글자 그대로**. 이 문서에 없는 설계 값 · 선택은 **채팅에서 먼저 묻는다**(결정거리는 쉬운 말로 · 맥락을 붙여 · 늘리지 않는다).
- 코드 · 설정 변경은 **이 문서에 적힌 것만**. 그 밖은 무엇을 만들고 고칠지 먼저 전부 설명하고 승인을 받는다. **HW · VZ · DS 코드는 고치지 않는다(제안만).**
- **`sudo` · 비밀번호 · 원격 서버 블록은 사람이 붙인다.** 비밀번호를 받지도 · 적지도 · 출력하지도 않는다. 환경 파일(`mission-history.env`)을 `cat` 하지 않는다. 토큰 값을 채팅에 내지 않는다.
- **DS · 쿠버네티스 · Redis · 다른 유닛을 건드리지 않는다** · `wsl --shutdown` · `wsl --terminate` 를 치지 않는다(T3 선택 시험만 · 주인 동의) · `tailscale up` 을 다시 치지 않는다.
- 원격 서버: 사용자가 직접 · `docker compose down` 금지 · PC ↔ 서버 전송은 `sftp -P 8522 dg@210.110.250.33`.
- **기록은 손으로 옮기지 않는다**(파일로). 작업로그는 정확하게 · 뒤에만 붙인다. 파일을 만들거나 고치면 **어느 경로의 어느 이름으로** 했는지 정확히 말한다.
- 수정본은 같은 이름으로 덮어쓰지 말고 **버전을 올린다**(v2 …). claude.ai 프로젝트에는 올리지 않는다.
- 문제는 **소프트웨어 · 설정을 먼저** 보고 물리(배선 · 회선)는 그다음. 되돌리는 법은 「비상용 — 돌리지 말 것」 으로 따로. 다이어그램 · 그림은 사용자가 요청하기 전에 만들지 않는다.
