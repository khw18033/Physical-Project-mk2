## 2. 옮기는 방법 — 1단계가 남긴 함정 둘을 먼저 읽어라

### ① `t()` 는 리렌더를 일으키지 않는다

```tsx
useLang();                      // ← 이게 없으면 그 부품만 옛 언어로 남는다
return <span>{t('mode.label')}</span>;
```

**증상이 「일부만 안 바뀐다」라 원인 찾기가 어렵다.** 파일마다 `t()` 를 처음 넣을 때
`useLang()` 을 같이 넣는다. 훅이 아닌 곳(순수 함수)에서 `t()` 를 부르면 **그 함수를 부르는
컴포넌트**가 `useLang()` 을 갖고 있어야 한다.

### ② 모듈 최상위 상수에서 `t()` 를 부르면 로드 시점에 굳는다

```ts
const PLANE_LABEL = { business: t('plane.business') };   // 나쁘다 — 영원히 안 바뀐다
<b>{t('plane.' + spec.plane)}</b>                        // 좋다 — 읽는 자리에서 부른다
```

시연 경로에 이런 상수가 **10곳** 있다. 전체로는 35곳이다. **표를 `t()` 로 바꾸지 말고
읽는 자리를 바꿔라.** 1단계가 `PLANE_LABEL` 에서 그렇게 했다.

대상 (실측): `pendingSources.ts` 2 · `UtterancePanel.tsx` 1 · `HelpOverlay.tsx` 2 ·
`ActionModal.tsx` 1 · `AppShell.tsx` 1 · `TaskGraph.tsx` 1 · `stateStyle.ts` 1 · `LangSwitch.tsx` 1

### ③ 치환은 자리표시로 — 시연 경로에 34곳

```ts
t('elapsed.prefix') + sec + t('elapsed.suffix')   // 나쁘다 — 영어로 옮길 방법이 없다
t('elapsed', { sec })                              // 좋다
```

1단계 시범 키 ②가 이것을 증명했다 — ko 는 숫자가 앞, en 은 뒤다.

### ④ 키 규칙 — `영역.항목`

한국어 원문을 키로 쓰지 마라. 용어집의 말을 키에도 쓴다 — `pending.*` · `script.*` ·
`task.state.*` · `device.status.*`.

**`상태` 를 기계적으로 치환하지 마라** (용어집 §2 ◆). 장치와 태스크가 다른 것이다.

## 4. 기본 언어는 `ko` 다 — 화면이 안 바뀐다

**이 단계의 합격 기준 절반이 이것이다.** `?lang=ko` 화면은 지금과 글자 하나 달라지면 안 된다.

- `t('x')` 가 돌려주는 ko 값은 **원문 그대로** 옮긴다. 다듬지 마라
- 다듬고 싶은 문구가 보여도 **이번에는 옮기기만 한다.** 문구 개선은 별건이다
- 두 벌이 생기지 않게 한다 — 원문을 지우고 사전으로 보낸다. 복사해 두지 않는다

**파일 하나를 옮기면 그 파일을 보는 검사도 같은 커밋에서 고친다.** 한 번도 빨간 채로
넘어가지 않는다.

### 고치는 방법 — 문구가 아니라 **키**를 본다

```js
// 지금 — 문구가 바뀌면 깨진다
check(source.includes('대본 닫기'), '대본 닫기 버튼이 없다');

// 이렇게 — 번역이 바뀌어도 안 깨진다
check(source.includes("t('script.close')"), '대본 닫기 버튼이 없다');
```

**키 대조로 바꾸는 것이지 검사를 무르게 하는 것이 아니다.** 어떤 검사든 「통과시키려고」
조건을 뺐다면 그건 실패한 작업이다.

사전에 그 키가 **실제로 있는지**도 같이 본다 — 키만 보면 오타가 안 잡힌다.

```js
const { ko } = await import('../src/i18n/ko.ts');
check(ko['script.close'] !== undefined, '사전에 script.close 가 없다');
```

### 신설 — `verify:i18n-demo-path`

**이 단계의 회귀 방지선이다.** 시연 경로 23개 파일에 **JSX 텍스트 노드로 박힌 한글이
0건**인지 본다. 사전을 우회한 자리를 잡는다.

- 주석·타입·대본 JSON 은 제외한다
- `ko.ts` 에 있는 키가 `en.ts` 에도 있는지 본다 — **시연 경로 키는 필수**
- 대조군 — 한글을 도로 박은 사본이 반드시 잡혀야 한다

5단계의 `verify:no-raw-korean` 이 이것을 전체로 넓힌 것이 된다.
