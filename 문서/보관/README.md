## `_archive/` 와 무엇이 다른가

**뜻이 다르다. 섞지 않는다.**

| 폴더 | 무엇 |
|---|---|
| `_archive/` | **고쳐지기 전 판.** 같은 문서의 옛 버전이다(`…_260903_수정전.md`) |
| `문서/보관/`(여기) | **그때 확정된 판인데 지금 자주 안 여는 것.** 틀린 문서가 아니다 |

**지운 것이 아니라 자리만 옮긴 것이다.** 규약 문서(`정지명령_규약_260910.md`·`탐지_명령규약_260910.md`)처럼
**코드가 지금도 주석에서 가리키는 것**이 여기 들어 있다 — 옮기면서 `문서/보관/…` 으로 경로를 같이 고쳤다.

## 다시 옮길 때

같은 기준을 쓰고 **이 폴더에 더한다.** 폴더를 새로 만들지 않는다 —
날짜별로 폴더가 갈라지면 「어느 보관함에 있더라」가 생긴다.

`reports/`·`viz-debugger/src/`·다른 문서에 흩어져 있다.

```bash
grep -rn --include=*.md --include=*.txt --include=*.ts --include=*.tsx "문서/<옮긴 파일 이름>" .
```
