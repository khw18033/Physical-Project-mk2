## 붙여 넣을 답신

구현 보고 잘 받았다. **계약과 다르게 한 11건은 전부 받아들인다** — 가시화 쪽에서 막히는 것이 없고, 몇 건은 가시화를 맞췄다(아래 2절).
`ETH_P_ALL` 로 고친 것(나가는 패킷)과 journal 을 `-o json` + `--after-cursor` 로 이어 받게 한 것은 특히 좋다.

### 1. §4.3 — 가시화 PC 에서 테일넷으로 붙었다

가시화의 실제 수신 코드(연결 관리 「확인」과 같은 경로)로 `ws://pi1.tailcb6bfb.ts.net:9001/mqtt` 에 **구독만** 해서 확인했다. 두 번 해서 둘 다 됐다.

```
브로커 ✓ · 중계 ✓ 603 ms — pi1 · go1-001 · 배터리 84% · yaw 6.6° (bridge_state)
nav_state 받은 것: battery_pct 84 · yaw_deg 6.6 · yaw_source bridge_state · yaw_odometry_deg -7 · moving false · path_active false
모양이 안 맞아 버린 건 0
```

### 2. 가시화 쪽에서 맞춘 것

- **시계 차.** 가시화 PC 와 pi1 의 `ts_ms` 가 **약 2.25초 어긋난다**(pi1 이 앞선다, 두 번 재서 −2263 · −2250 ms).
  보고 §6-10(브로커가 끊긴 동안 `nav_event` 를 큐에 뒀다가 다시 보냄)과 겹치면 늦게 온 사건이 도착 순간에 몰려 칠해지므로,
  가시화가 `nav_state` 로 시계 차를 재서 **2초 넘게 늦게 온 사건만** 일어난 시각으로 되돌린다. 제때 온 사건은 받은 시각 그대로 쓴다.
  → 부탁: pi1 에서 `timedatectl` · `chronyc tracking`(또는 `timesyncd`) 로 시간 동기가 되는지 봐 달라. 어느 쪽 시계가 틀렸는지는 가시화도 모른다. 동기 설정을 바꿔야 하면 **먼저 보고**한다.
- `path_cancel` 이 끝난 경로를 가리킬 수 있는 것(§6-3): 가시화는 이동이 진행 중이 아니어도 `path_cancel` 을 재탐색 시작으로 받는다. `note` 는 액션 아이템에 그대로 보인다.
- `point_count` 가 브리지 waypoint 수인 것(§6-7), `battery_pct` 정수(§6-9), `yaw_source` 가 null 일 수 있는 것(§6-2): 가시화가 이미 그렇게 읽는다.

### 3. 부탁 하나 — journal 문구가 바뀌면 조용히 끊긴다

보고에 `go1_sdk_pc.cpp` 가 작업 트리에서 수정 상태(` M`)라고 했다. 누가 그 트리로 다시 빌드해 `[PATH] activated …` · `PATH_CANCEL received` · `done notify sent (mode=99)` 문구가 바뀌면,
경로 사건이 **오류 없이 안 나오기만** 한다. 가시화는 그걸 「경로가 안 왔다」로 읽는다.

- 중계 로그에 경고를 남겨 달라: **5009 `motion_active=true` 가 10초 넘게 이어지는데 이 프로세스에서 journal 경로 사건이 한 번도 안 나왔으면** 한 번 적는다. 사건을 지어내지는 않는다.
- 이 경고를 `nav_event` 로 보내지는 않는다(계약에 없는 사건이다). 중계 로그에만 남긴다.

### 4. 다음 — §4.4 실제 유니티 경로 시험

남은 확인은 **실제 `go1-sdk` 로그 줄로 사건이 나오는가** 하나다. 사람이 입회하고 가시화와 시간을 맞춰 한다. 그때 볼 것:

1. 짧은 경로 한 건 → `path_received`(id · waypoints) → 도착 → `path_done` 이 **각 한 건**
2. 이동 중 경로 변경(PATH_CANCEL + 새 경로) → `path_cancel` → `path_received` 순서, 새 id
3. **CHUNK 로 쪼개지는 긴 경로** 한 건 → `path_received` 한 건
4. 각 사건의 journal 줄 시각과 `nav_event.ts_ms` 를 나란히 (가시화는 받은 시각과 견준다)

시험이 끝나면 위 네 가지의 실제 출력만 짧게 보고해 달라.
