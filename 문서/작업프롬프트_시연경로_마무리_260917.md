## 1. 남은 9건 — 자리표시로 옮긴다

**조각을 이어붙이지 마라.** 2단계 §2 ③과 같은 규칙이다.

```tsx
<span className="history-count">{entry.done}/{entry.of} 노드</span>        // 지금
<span className="history-count">{t('hist.nodes', { done, of })}</span>     // 이렇게
// ko: '{done}/{of} 노드'   en: '{done}/{of} nodes'
```

`{}초` · `{}판` · `{}구간` 처럼 **숫자에 붙는 단위**는 영어에서 어순도 띄어쓰기도 다르다.
`3판` 은 `3 runs`, `{}구간 —` 은 `{} segments —`. 한 키 안에 문장째로 넣어야 옮길 수 있다.

`UtterancePanel:774` 는 **문장이고 목록 조인이 가운데 있다.** 목록은 먼저 만들고 자리표시로
넣어라 — `t('utt.markers', { list })`.

용어집을 따른다 — `노드 → Node` · `구간 → segment` · `판 → run`(임무 한 판).
**새 말을 지어내면 용어집에 한 줄 더한다.**

## 2. 검사의 사각 — 한 줄이다

```js
// scripts/verify-i18n-demo-path.mjs:60
const jsxText = [...src.matchAll(/>([^<>{}]*[가-힣][^<>]*)</g)]
//                                 ^^^^^^^^ 중괄호를 배제한다
```

앞쪽 `[^<>{}]*` 때문에 **보간식 옆 텍스트는 매칭 대상이 아예 안 된다.**
`<small>{items.length}판</small>` 이 통과하는 이유가 이것이다.

### 고치는 방향 — 오탐을 같이 잡아야 한다

0절의 방법(표현식을 비운 뒤 `>…<`)이면 9건을 다 잡는다. **다만 그대로 쓰면 오탐이 둘 난다** —
코드의 비교 연산자를 텍스트 경계로 오인한다.

```
graph/TaskGraph.tsx   « = 0; const x1 = from.x + from.w / 2; …»
views/UtterancePanel.tsx  «{ if (!manual.trim()) return; …»
```

줄바꿈을 막으면(`[^<>\n]`) 오탐은 사라지지만 **여러 줄 JSX 2건을 놓친다**
(`UtterancePanel:242` · `MissionHistory:204`). 둘을 섞어야 한다 — 예를 들어 표현식을 비운 뒤
`;` · `=>` · `const ` · `return ` 이 든 조각을 버린다.

**어떻게 갈랐는지 보고서에 적어라.** 5단계 `verify:no-raw-korean` 이 이 규칙을 저장소 전체로
넓힌다 — 거기서 오탐이 나면 아무도 검사를 안 본다.

### 대조군을 늘린다

지금 대조군 4건은 **박힌 한글을 잡는지**만 본다. `{}판` 꼴을 하나 더한다 —
**이번에 뚫린 모양이 다시 뚫리면 잡혀야 한다.**

## 3. `useLang()` 검사를 컴포넌트 단위로 — 예방이다

```js
// scripts/verify-i18n-demo-path.mjs — 지금
if (!/useLang\(\)/.test(src)) failures.push(...);   // 파일에 하나라도 있으면 통과
```

2단계에서 네 번 빠뜨렸고 **넷 다 「한 파일에 컴포넌트가 여럿」인 모양**이었다
(보고서 §4 ①). 파일 단위 검사는 그 넷 중 하나도 구조적으로는 못 잡는다 — `AppShell` 을
잡은 것은 그 파일에 컴포넌트가 하나였기 때문이다.

### 지금은 다 채워져 있다

| 파일 | 컴포넌트 | `useLang()` |
|---|---:|---:|
| `PlanApproval.tsx` | 6 | 6 |
| `ActionModal.tsx` · `StopButton.tsx` | 4 | 4 |
| `UtterancePanel.tsx` · `MissionHistory.tsx` | 3 | 3~4 |
| `ResetButton.tsx` · `ConnectionsPanel.tsx` | 2 | 2~3 |

**그래서 이건 고치는 일이 아니라 못박는 일이다.** 4단계가 1,300여 개를 옮기는 동안
같은 함정을 훨씬 더 많이 밟는다. 그때 잡히게 지금 조인다.

### 할 일

`t()` 를 **부르는 컴포넌트마다** `useLang()` 이 있는지 본다.

- 컴포넌트 경계는 `function [A-Z]…` 로 가른다. 화살표 컴포넌트가 있으면 같이 본다
- 훅이 아닌 순수 함수에서 `t()` 를 부르는 것은 정상이다 — **그리는 컴포넌트**가 가지면 된다.
  그 구분을 못 하겠으면 `.tsx` 안의 대문자 함수만 본다 (지금 잣대와 같다)
- 대조군 — 두 번째 컴포넌트에서 `useLang()` 을 뺀 사본이 잡혀야 한다.
  **이것이 이 절의 핵심이다.** 대조군이 안 잡으면 조인 것이 아니다
