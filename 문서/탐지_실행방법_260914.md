# 탐지 프로그램 실행 방법 — 데스크톱(Windows) (2026-09-14)

탐지는 GPU 가 있는 데스크톱 **`desktop-oaujese`** 에서 돈다. 시연장에 못 가져가므로
관제 웹(노트북) · 로봇(pi7) · 탐지(데스크톱)가 전부 **테일넷**으로 붙는다.

```
시연장                                     데스크톱
pi7 MQTT 브로커 ── 프레임+각도 ──▶  창 2  mqtt_stream_receiver.py
노트북 브라우저 ◀── GET 폴링 ─────  창 1  detect_api_server.py :8000
```

탐지 코드는 탐지 담당 저장소 [`JNY03/physical_demo`](https://github.com/JNY03/physical_demo) 를
저장소 루트에 클론해 둔 것이다(`.gitignore` 로 올리지 않는다). 가상환경은 그 안의 `venv` 이고
Python 3.12 · torch 2.14.0(CUDA 13.0) 으로 구성해 두었다.

---

## 전제 — 한 번만

**방화벽.** PowerShell 을 **관리자 권한**으로 열고 한 번 실행한다. 테일넷(100.64.0.0/10)에서
오는 8000 포트만 연다. 이게 없으면 창구를 처음 띄울 때 Windows 가 허용 창을 띄우고, 아무도
안 누르면 노트북의 요청이 막힌다.

```powershell
New-NetFirewallRule -DisplayName "detect-api 8000 (tailnet)" -Direction Inbound -Protocol TCP -LocalPort 8000 -RemoteAddress 100.64.0.0/10 -Action Allow
```

## 매번 실행 — 창 두 개

아래 명령은 cmd 와 PowerShell 양쪽에서 그대로 된다. 둘 다 `demo\test` 에서 **가상환경의
python** 으로 실행한다.

### 창 1 — 관제 웹용 HTTP 창구

```bat
cd C:\Users\user\Desktop\khw\Physical-project-mk2\physical_demo\demo\test
..\..\venv\Scripts\python.exe detect_api_server.py --port 8000
```

- torch 없이 바로 뜬다. `try1\` 를 **읽기만** 한다.
- 떴는지는 이 PC 브라우저에서 `http://127.0.0.1:8000/health` 를 연다 — `"ok": true` 면 된다.

### 창 2 — 로봇 프레임 수신 + 탐지

```bat
cd C:\Users\user\Desktop\khw\Physical-project-mk2\physical_demo\demo\test
..\..\venv\Scripts\python.exe mqtt_stream_receiver.py --target door
```

- 로봇 브로커 `ws://pi7.tailcb6bfb.ts.net:9001/mqtt` 에 붙어 기다린다. 로봇이 한 바퀴(8장)를
  돌면 **탐지 → 자기 위치 추정 → 경로 산출**까지 알아서 끝낸다. 관제 웹은 명령을 보내지 않는다.
- **모델 넷을 올리는 데 수십 초가 걸린다 — 시연 전에 미리 띄워 둔다.** 발표 직전에 띄우면
  첫 스캔을 놓친다.
- 새 스캔이 시작되면 이전 판 결과(`try1\`)를 지운다. 남겨야 할 결과가 있으면 먼저 복사해 둔다.

### 끌 때

두 창에서 **Ctrl+C**. 창 2 가 꺼져 있으면 로봇이 스캔해도 결과가 생기지 않고, 창 1 이 꺼져
있으면 노트북 화면에 「닿지 않습니다」가 뜬다.

## 막히면 먼저 볼 것

`demo\test` 에서 실행한다.

| 확인할 것 | 명령 |
|---|---|
| 로봇(pi7)에 닿는가 | `tailscale ping pi7` |
| 브로커에 무엇이 흐르는가 (20초 듣고 끝) | `..\..\venv\Scripts\python.exe mqtt_stream_receiver.py --sniff` |
| 로봇 없이 파이프라인 전체가 도는가 (데이터셋 8장) | `..\..\venv\Scripts\python.exe mock_stream_receiver.py` |

`mock_stream_receiver.py` 는 2026-09-14 에 이 PC 에서 끝까지 돌았다 — 문 270°·315°, 로봇 위치
[238.0, 127.4] cm, 「왼쪽 74.6° 회전 → 633.6 cm 직진」. 이것도 `try1\` 를 덮어쓴다.

실행 중에 뜨는 `symlink` · `xFormers not available` · `EdgeGuidedLocalSSI … slowdown` 경고는
결과에 영향이 없었다.

(`http://desktop-oaujese.tailcb6bfb.ts.net:8000`). **「확인」** 만 누르면 된다.
이름이 안 풀리면 네트워크 환경을 **Tailscale (IP)** 로 바꾼다(`http://100.125.71.51:8000`).
