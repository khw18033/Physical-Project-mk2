## 1. 줄끝 — 대조군이 CRLF 에서 안 만들어진다

### 지금

`verify-trace-append.mjs:139-143` 의 대조군 둘이 **여러 줄 문자열**을 찾는다.

```js
source.replace(
  'let index = this.events.length;\n    while (index > 0 && ...',   // ← \n
  'return this.events.length;',
)
```

`traceStore.ts` 는 **CRLF** 다. 그래서 이 치환이 아무것도 못 바꾸고
「대조군을 만들지 못했다」로 떨어진다. 한 줄짜리 대조군 둘은 멀쩡히 통과한다 —
**여러 줄을 찾는 것만 죽는다.**

이 저장소는 소스 173개가 CRLF 이고 LF 는 5개뿐이다. 즉 **줄끝을 맞추는 쪽이 아니라
검사가 줄끝을 안 보는 쪽**으로 고쳐야 한다. `.gitattributes` 로 저장소 전체 줄끝을
바꾸는 것은 **하지 마라** — 173개 파일이 통째로 diff 에 뜬다.

### 할 일

**소스를 읽는 자리를 하나로 모은다.**

```js
// scripts/lib/source.mjs (신설)
export function readSource(...parts) {
  // 대조군은 **여러 줄을 찾는다.** 작업본 줄끝이 무엇이든 검사가 같게 돌아야 한다.
  return readFileSync(join(...parts), 'utf8').replace(/\r\n/g, '\n');
}
```

`verify-trace-append.mjs` 가 이것을 쓰게 바꾼다. 치환 문자열은 **안 고친다** — 지금
`\n` 으로 적혀 있는 것이 맞고, 읽는 쪽이 맞춰 주면 된다.

### 나머지 스크립트는 **훑되 고치지 마라**

여러 줄 치환을 쓰는 스크립트가 더 있다. 지금은 안 깨져 있다 — 찾는 문장이 한 줄이거나
그 파일이 LF 이기 때문이다. **깨지지 않은 것을 예방 삼아 고치지 마라.**

대신 **목록만 만들어 보고서에 적어라** — 「여러 줄을 찾는 대조군을 가진 스크립트」와
그 파일의 현재 줄끝. 다음에 누가 그 파일을 만졌을 때 어디가 터질지가 그 표에 있다.

## 2. 한글 경로 — `.pathname` 은 퍼센트 인코딩이다

### 지금

```js
// scripts/verify-places.mjs:13 · scripts/extract-places.mjs:21 — 같은 줄이 두 벌
const ROOT = new URL('../../', import.meta.url).pathname.replace(/^\/([A-Za-z]:)/, '$1');
```

`URL.pathname` 은 **퍼센트 인코딩된 문자열**이다. 저장소 경로에 한글이 있으면
`대학` 이 `%EB%8C%80%ED%95%99` 로 남은 채 `readFileSync` 에 들어가 `ENOENT` 가 난다.

```
pathname       C:/Users/user/Desktop/%EB%8C%80%ED%95%99/…   ← 파일 못 연다
fileURLToPath  C:\Users\user\Desktop\대학\…                  ← 맞다
```

리눅스나 영문 경로에서는 안 깨진다. **이 저장소가 한글 경로에 있는 동안만 빨갛다.**

### 할 일

```js
const ROOT = fileURLToPath(new URL('../../', import.meta.url));
```

`fileURLToPath` 가 디코딩과 윈도우 드라이브 문자를 **둘 다** 처리한다.
**손으로 붙인 `.replace(/^\/([A-Za-z]:)/, '$1')` 는 지운다** — 그게 있어야 할 이유가 없어진다.

두 파일 다 같은 줄이다. `scripts/` 전체에 `.pathname` 을 파일 경로로 쓰는 자리가 더 있는지
훑어라 — `gateway/server.ts` 의 `url.pathname` 은 **HTTP 경로**라 해당 없다. 건드리지 마라.

## 3. 임시 폴더 — 검사가 서로를 오염시킨다

### 이게 제일 크다

검사 13개가 대조군 사본을 `src/` **안에** 만든다. 상대 import 가 풀려야 하기 때문이고,
그 자체는 맞는 설계다. 문제는 **정리가 실패해도 조용히 넘어간다**는 것이다.

```js
// verify-trace-append.mjs:159
try { rmSync(scratch, { recursive: true, force: true }); }
catch { console.warn('임시 디렉터리 정리 실패 — ' + scratch); }
```

그리고 남은 잔여물이 **다른 검사의 판정을 바꾼다.** 260917 에 실제로 이랬다.

```
❌ verify:trace-append
- 기록 열을 따로 만드는 곳이 있다: src/data/.verify-human-acukey/trace-3.ts, … 6건
```

**`verify:human-trace` 가 흘린 파일을 `verify:trace-append` 가 위반으로 셌다.**
지우고 다시 돌리니 그 줄이 사라졌다.

### `.gitignore` 가 증상을 덮고 있었다

```
viz-debugger/.verify-placeholder-*/
viz-debugger/**/.verify-scenario-*/
…  8줄
```

주석에 「끝나면 스스로 지운다」고 적혀 있는데 **안 지워지니까 한 줄씩 늘어난 것**이다.
새 검사를 만들 때마다 여기 한 줄을 더하는 것이 관행이 됐다.

### 할 일 넷

**① 판정이 잔여물에 안 흔들리게 한다 — 이게 뿌리다.**
`src/` 를 훑는 검사는 전부 `.verify-*` 를 **제외**한다. 남의 쓰레기가 내 판정을 바꾸면
안 된다. 잔여물이 0이어도 이 제외는 넣는다 — 정리는 실패할 수 있고, 판정은 아니다.

**② 공용 헬퍼 하나.** `scripts/lib/scratch.mjs`

- 만들 때 **같은 접두사의 오래된 형제를 먼저 지운다.** 앞 실행이 흘렸어도 다음 실행이 치운다
- 정리 실패를 `console.warn` 으로 삼키지 말고 **`failures` 에 올린다.** 조용한 실패가 이 사태의
  뿌리였다. 검사 결과는 통과시키되 마지막에 「N개를 못 지웠다」를 **반드시 눈에 띄게** 적는다
- 13개 스크립트를 이걸로 옮긴다

**③ `npm run verify:clean`** — 잔여물을 한 번에 비운다. `package.json` 에 넣는다.

**④ `.gitignore` 8줄을 한 줄로.**

```
viz-debugger/**/.verify-*/
```

접두사를 손으로 적는 목록은 다음 검사에서 또 어긋난다.

## 4. 하지 않을 것

- **`src/` 의 동작 코드 수정.** 화면은 한 글자도 안 바뀐다
- **`.gitattributes` 로 저장소 줄끝 통일** — 173개 파일이 diff 에 뜬다. §1 참조
- **안 깨진 스크립트를 예방 삼아 고치기** — 목록만 만든다 (§1)
- **`gateway/server.ts` 의 `url.pathname`** — HTTP 경로다. 해당 없다
- **검사의 판정 기준 완화.** 이 작업은 **거짓 실패**를 없애는 것이지 기준을 무르게 하는 것이 아니다.
  어떤 검사든 「통과시키려고」 조건을 뺐다면 그건 실패한 작업이다
- 영문화 2단계 착수

| 검사 | 무엇을 |
|---|---|
| **`verify:*` 전종** | **58 통과 / 0 실패.** 이것이 이 작업의 합격 기준이다 |
| **두 번 연속** | 한 번 돌리고 **곧바로 또 돌린다.** 두 번째도 58/0 이어야 한다 — 첫 실행의 잔여물이 두 번째를 깨뜨리면 §3 이 덜 된 것이다 |
| **잔여물** | 전종 실행 뒤 `find . -name ".verify-*"` 가 **0개** |
| `verify:places` | 한글 경로가 든 이 저장소에서 통과하는가 |
| `verify:trace-append` | 대조군 **넷 다** 만들어지는가 — 「대조군을 만들지 못했다」가 한 줄도 없어야 한다 |
| **신설 `verify:verify-hygiene`** | 아래 |

### 신설 — `verify:verify-hygiene`

**다시 켜지지 않게 하는 것이 이 작업의 진짜 산출물이다.** 없으면 석 달 뒤 같은 보고서를 쓴다.

`scripts/verify-verify-hygiene.mjs` — 검사 스크립트 자신을 검사한다.

1. `scripts/*.mjs` 중 파일 경로를 만드는 데 **`.pathname` 을 쓰는 자리가 없다** (`fileURLToPath` 를 쓴다)
2. 대조군 사본을 만드는 스크립트는 **공용 헬퍼를 쓴다** — 직접 `mkdtempSync` 를 부르지 않는다
3. `src/` 를 훑는 검사는 **`.verify-*` 를 제외한다**
4. 대조군 — 위 셋을 어긴 사본이 반드시 잡혀야 한다
