## 왜 하나

영문화에서 순서를 틀리면 두 번 일한다.

문자열부터 뽑아내면 **옮겨 놓을 데가 없다.** 사전과 `t()` 가 먼저 있어야 추출이 곧바로 붙는다.
그리고 골격만 놓고 한 번 보이면, 용어와 범위를 **번역 1,000줄 쓰기 전에** 고칠 수 있다.
2단계에 들어간 뒤 「자리표시를 Pending 이 아니라 Placeholder 로」 같은 말이 나오면 사전을 통째로 다시 만진다.

그래서 이번 산출물은 **갈아끼울 통로 하나**다. 통로가 도는지는 시범 키 다섯 개로 증명한다.

## 1. 언어 저장소 — `src/shared/language.ts`

`connections.ts` 와 **같은 꼴**로 짠다. 셋째 패턴을 만들지 마라.

```ts
export type Lang = 'ko' | 'en';
export const LANGS: readonly Lang[] = ['ko', 'en'];

export function getLang(): Lang;
export function setLang(next: Lang): void;
export function subscribeLang(listener: () => void): () => void;
export function useLang(): Lang;          // useSyncExternalStore
```

### 결정 순서

```
?lang=   >   localStorage   >   navigator.language   >   'ko'
```

- **URL 을 맨 위에 두는 것이 요점이다.** 링크 하나로 영문 화면을 그대로 건넬 수 있어야 한다.
  「일반적인 웹사이트처럼」이라는 요청의 실질이 이것이다
- `?lang=` 으로 들어오면 **그 값을 `localStorage` 에도 적는다.** 새로고침에 살아남아야 한다
- 목록에 없는 값(`?lang=jp`)은 무시하고 다음 순서로 떨어진다. 던지지 않는다
- `navigator.language` 는 `'en-US'` 처럼 지역이 붙어 온다. 앞 두 글자만 본다
- `localStorage` 가 없는 환경에서도 동작해야 한다 — `connections.ts` 가 이미 그렇게 짜여 있다

### 언어가 다른 상태를 건드리지 않는다

`setLang()` 이 `renderMode` · 연결 주소 · 기록 열 중 무엇도 못 바꾸게 한다.
**언어는 표시층의 설정이고, 그 밖으로 새면 안 된다.** 6절이 이걸 검사한다.

## 2. 사전 — `src/i18n/`

### `dict.ts`

```ts
export function t(key: string, vars?: Record<string, string | number>): string;
```

**세 가지를 지킨다.**

**① 키는 `영역.항목`.** 한국어 원문을 키로 쓰지 마라.

```ts
t('stt.offline')                    // 좋다
t('STT 서비스에 닿지 않습니다')       // 나쁘다 — 원문을 다듬으면 영어가 떨어진다
```

**② 누락은 한국어로 떨어진다.**

```
en 에 키가 없으면  →  ko 값을 돌려주고 콘솔에 한 줄
ko 에도 없으면    →  키 문자열을 돌려주고 콘솔에 경고
```

빈 문자열을 그리지 마라. 키 원문(`stt.offline`)이 화면에 뜨게 두지도 마라.
**부분 번역 상태로도 화면이 정상이어야 한다** — 4단계까지 1,249줄을 다 못 옮긴다는 전제로 설계한 것이다.

콘솔 한 줄은 같은 키에 대해 **한 번만** 찍는다. 렌더마다 찍으면 콘솔이 못 쓰게 된다.

**③ 치환은 자리표시로.** 문장을 쪼개 이어붙이지 마라.

```ts
t('elapsed', { sec: 30 })
// ko: '경과 {sec}초'   en: '{sec}s elapsed'
```

영어는 어순이 반대라, 조각을 이어붙이는 순간 번역이 불가능해진다.
`${}` 가 섞인 한글 문자열이 저장소에 **164곳** 있고 2단계에서 전부 이 꼴로 옮긴다.

복수형(`Intl.PluralRules`)은 넣지 마라. 언어가 둘뿐이라 과하다.

### `ko.ts` · `en.ts`

같은 모양의 평평한 객체 하나씩. 중첩하지 마라 — 키에 점이 들어 있으니 구조는 이름이 진다.

## 3. 전환 UI — `src/shell/LangSwitch.tsx`

`ModeSwitch.tsx` 를 본떠 세그먼트 하나. `global-bar` 우측, `ModeSwitch` 옆.

```
모드 [ 일반 ][ 시나리오 ▾ ][ 목·개발 ]        언어 [ 한국어 ][ English ]
```

- 라벨은 **각 언어를 그 언어로** 적는다 — `한국어` · `English`. 번역하지 않는다.
  영문 화면에서 `Korean` 이라고 적으면 한국어를 찾는 사람이 못 찾는다
- 전환할 때 `document.documentElement.lang` 을 같이 바꾼다. 줄바꿈 규칙과 스크린리더가 이걸 본다
- URL 의 `?lang=` 도 같이 갱신한다 (`history.replaceState`). **주소창을 복사하면 그 언어가 따라가야 한다.**
  `pushState` 가 아니다 — 뒤로가기가 언어 전환 이력으로 채워지면 안 된다

### 라우터를 넣지 않는다

`/ko` · `/en` 경로 분리는 하지 마라. 지금 의존성은 넷(`react`·`mqtt`·`protobufjs`·`ws`)이고,
라우터 하나 넣자고 `verify:dep-rules` 가 지키는 선을 넘을 일이 아니다.
`standalone.html` 단일 파일에서는 경로 분리가 **아예 동작하지 않는다.**

## 4. 시범 키 다섯 — 골격이 도는 증거

빈 사전만 두면 통로가 도는지 확인할 방법이 없다. **다섯 개만** 실제로 영어까지 채운다.

서로 다른 성질을 하나씩 고른다.

| # | 성질 | 후보 |
|---|---|---|
| 1 | 단순 라벨 | `모드` |
| 2 | **치환이 있는 문장** | 경과 시간처럼 `${}` 가 든 것 하나 |
| 3 | **긴 오류 문장** | `STT 서비스에 닿지 않습니다 (…)` — 줄바꿈이 레이아웃을 깨는지 본다 |
| 4 | 열거형 라벨 | `PLANE_LABEL` 중 하나 |
| 5 | **en 을 일부러 비운 키** | fallback 이 도는지 눈으로 확인 |

다섯째가 중요하다. **fallback 이 실제로 한국어를 그리고 콘솔에 한 줄 남기는지**를 이 단계에서 봐 둬야,
2단계에서 수백 개가 비어 있어도 안심하고 진행한다.

## 5. 하지 않을 것

- **문자열 추출.** 2단계 일이다. 시범 다섯 개 말고는 컴포넌트를 건드리지 마라
- **번역.** 시범 다섯 개의 영어도 가안이다. 용어집이 확정되면 바뀐다
- `registry.json` · `scenarios/*.json` — 3단계
- `stt/` · `gen-lab/` 어느 파일도 — 3·5단계
- 기존 verify 스크립트 수정 — 5단계
- 라우터·i18n 라이브러리 도입
- `pendingSources.ts` 의 타입 리터럴 (`'하드웨어' | 'AI' | '백엔드'`) — 파트명이 확정된 뒤 2단계

## 6. 검증

| 검사 | 무엇을 |
|---|---|
| **`verify:lang-switch`** (신설) | `setLang()` 전후로 `renderMode` · 연결 주소 · 기록 열이 **안 바뀌는가**. 언어가 다른 상태를 오염시키지 않는다 |
| 손 확인 · 결정 순서 | `?lang=en` · `localStorage` 만 · 둘 다 · 둘 다 없음 · `?lang=jp` — 다섯 경우가 각각 맞는 언어로 뜨는가 |
| 손 확인 · fallback | 시범 키 다섯째가 **한국어로 뜨고 콘솔에 한 줄** 남기는가. 같은 키가 렌더마다 반복해 찍히지 않는가 |
| 손 확인 · 새로고침 | `?lang=en` 으로 들어와 주소창을 지우고 새로고침해도 영어가 유지되는가 |
| **`verify:standalone`** | 단일 파일 빌드에 사전이 실리고, 그 파일에서도 `?lang=en` 이 동작하는가 |
| 기존 verify 전종 | **통과.** 이 단계는 화면 문구를 안 바꾸므로 하나도 깨지면 안 된다 |

마지막 줄이 이 단계의 합격 기준이다. **기존 검사가 하나라도 깨졌다면 골격이 영역을 넘은 것이다.**

## 8. 이 단계가 끝나면

**멈추고 교수님께 보인다.** 다음 셋을 확정받고 2단계로 간다.

1. 용어집 (0단계 산출물) — 특히 마일스톤·자리표시·대본·되감기
2. 파트명 영문 표기 (Hardware / AI / Backend) — `pendingSources.ts` 타입이 여기 걸린다
3. 시연 경로에 무엇을 넣을지 — `verify:i18n-complete` 가 **필수로 잡을 키 집합**이 된다
