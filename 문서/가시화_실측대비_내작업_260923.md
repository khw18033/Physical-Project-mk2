## 1. 🔴 먼저 — 「붙어 보는 시점을 미뤄라」는 취소됐다

09-21 회신(`vz-media-interface.md` §15-2)은 *"엣지 브릿지가 선 뒤에 붙어 달라"* 였다.
**09-22 정정(§16)이 그것을 취소했다.**

| | |
|---|---|
| 맞았던 사실 | 실로봇 업무 데이터가 지금 서버로 **0** 인 것은 맞다(HW 가 말단 브로커를 엣지로 돌렸고 엣지 브릿지가 안 섰다) |
| 🔴 틀린 결론 ① | *"그래서 기다려라."* 기준 문서 **단계 4-b** 가 **이 상황을 위해** 있다 — 가짜 발행자(`tests/publisher.py`)가 **서버** 브로커로 보내고 서버 브릿지가 받는다. **엣지 노트북도 tailnet 도 필요 없다** |
| 🔴 틀린 결론 ② | **`/media` 까지 같이 막았다.** 관문 B 는 업무 평면과 **아무 상관이 없다** — 합성 프레임을 백엔드가 만들어서 백엔드가 보낸다 |
| 왜 나쁜가 | 기준 문서 §4 원문: *"노트북 없이 「서버 → 뷰어」를 두 평면 모두 닫아 두면, 나중에 실영상·실데이터가 안 보일 때 **원인이 뷰어 쪽이 아니라는 것을 이미 안다.**"* §15-2 는 그 순서를 **거꾸로** 만들었다 |

> 그리고 내가 09-21 답신에서 물은 **「관문 C-a 를 시도하기 전에 알려 달라」** 가 이 건의 물음이었다.
> 백엔드가 §16-1 에 *"「시도해도 된다」가 답이었어야 했다"* 고 적었다. **물음 자체는 옳았다.**

## 3. 🔴 붙었을 때 「이상해 보이지만 합격」인 것 넷

**이번 실측에서 시간을 가장 많이 버릴 수 있는 자리다.** 미리 알고 붙는다.

| # | 보이는 모습 | 판정 | 왜 |
|---|---|---|---|
| ① | **로봇 상태가 「알 수 없음」** | 🔴 **합격 모습** | 어댑터가 `payload` 에 원래 메시지를 **통째로** 넣는다. `StateLayers` 3층이 아니다. 임시 구현에 3층을 억지로 채우면 그 모양이 굳으므로 **안 채우기로 합의**했다(Phase 5 이월). 이번에 판정하는 것은 **「경로가 살아 있는가」** 뿐이다 |
| ② | **붙자마자 화면이 안 찬다** | 정상 | 구독 즉시 캐시 1회 푸시(VZ-I-02)가 아직 없다. 로봇 상태는 1초, **평시 센서는 최대 1분**까지 빈다 |
| ③ | **영상이 최대 0.49초 멈췄다 재개** | 정상 | 로봇 인코더 IDR 이 0.49초 고정(환경변수로 못 바꾼다). 느린 링크에서 서버 drop-old 가 걸리면 다음 키프레임까지 공백 |
| ④ | **「연결됨인데 영상 없음」** | 정상일 수 있다 | 엣지가 안 붙어 있으면 소켓은 열리고 프레임만 안 온다 |

### 빈 화면일 때 의심 순서 (§16-3 — 되돌려진 최신판)

```
0️⃣ 백엔드가 발행자를 켜 뒀는가   ← 시각을 잡아 두면 변수에서 빠진다
1️⃣ 🔴 구역 값이 zoneA 인가        ← 다시 1순위. zone-503 이면 연결되고 0건
2️⃣ channel 이 status 인가         ← 구독자에게 안 간다(§6 ② 결정 대상)
3️⃣ 선택자가 dict 인가             ← 깨지면 전량 푸시로 안 물러선다. 0건
4️⃣ 토큰                           ← 그건 4401 로 먼저 끊긴다
```

<a id="s4-3"></a>

### 4-3. 🟡 `alignment` 부재 처리 — **기한부로 수용됐다. 되돌릴 시점을 놓치면 안 된다**

지금 우리 구현:

```
alignment === 'frame'   프레임 정합
그 밖의 값이 실려 옴     정합하지 않는다 (사용자 토글이 켜져 있어도)
값이 아예 없음           옛 계약 — 사용자 토글이 정한다        ← 백엔드 규칙과 다른 줄
```

백엔드가 **수용했다.** 근거는 *"지금 실경로로 오는 탐지가 0건"* 이고 `detections.schema.json` 이
아직 어떤 검증 경로도 로드하지 않는 초안이라, **`alignment` 없이 오는 것은 오늘 기준 목 데이터뿐**이라서다.

🔴 **다만 기한이 붙었다 — 실물 탐지가 백엔드 경로로 오기 시작하면 「부재 = unaligned」로 되돌린다.**
그때부터 백엔드 규격은 `alignment` 를 **항상** 싣기 때문에, 부재는 「옛 계약」이 아니라 **생산자 결함**이다.
결함을 토글로 덮으면 **틀린 박스가 맞는 것처럼 보인다.**

> **트리거:** 탐지 채널·토픽이 배선되는 시점(Phase 6), 또는 AI(진나영)가 백엔드 경로로 탐지를 보내기 시작할 때.
> **이 줄을 여기 적어 두는 이유가 그것이다** — 안 적으면 그 시점에 아무도 못 찾는다.

### 4-4. ⚪ `VZ-C-07` 문면 재협상 — 내 요구사항이니 내가 고친다

현 문면은 *"구독·명령 출구는 여전히 하나다"* 인데 실제로는 **소켓이 둘**이다(`/state`·`/media`).
`verify:one-gateway` 검사는 파일 단위 정규식이라 통과하지만 **문면은 우회되지 않는다.**

→ **「게이트웨이 주소는 하나, 소켓은 경로별 둘」** 로 고친다.
백엔드도 *"그쪽 요구사항이니 그쪽이 고치는 것이 맞다"* 로 동의했다.

### 5-1. 🔴 드론 `state` 본문 항목 목록 → `문서/CONTRACT_x500.md` §13

백엔드가 §16-4 에 *"이것 하나가 실제로 남은 것이다"* 라고 적은 항목인데,
**`CONTRACT_x500.md` §13 이 정확히 그 목적으로 쓰여 있다** —
제목이 *「백엔드 규격용 — `state.drone.schema.json` 을 만들 때 보는 표」* 다.

| 있는 것 | 절 |
|---|---|
| 공통 헤더 8칸(타입·필수·없을 때) | §13-1 |
| `state` 본문 최상위 14칸 | §13-2 |
| 중첩 객체(`battery`·`flight`·`gps`·`attitude`·`altitude`·`warnings`) | §13-3 |
| `reason` 어휘 **6개**(Go1 의 3개 + 드론 고유 3개) | §13-4 |
| **실제 발행된 `state` 1건 원문** | §13-5 |

🔴 **규격을 쓸 때 반드시 반영돼야 하는 규칙 둘**(§13-0):

1. **키는 항상 있다. 없는 것은 값이지 키가 아니다** → 전부 `required` 에 넣고 타입 쪽에서 `["object","null"]` 을 허용한다.
2. **`null` 을 0 으로 치환하지 말 것** — `null` 은 "모른다", `0` 은 "쟀더니 0". `battery: null` 을 0% 로 읽으면 잘못된 경보가 된다.

→ **전달은 [답신](백엔드_답신_260923.md) 에서 한다. 내가 새로 쓸 것은 없다.**

## 7. 붙을 때 참조표 — 확정된 규격

### `/state` 로 받는 것

```json
{ "type": "data", "sub": "<내가 붙인 구독 ID 그대로>", "envelope": { "...11칸...": "" } }
```

| 칸 | 값 | 주의 |
|---|---|---|
| `zone`·`node`·`entity` | `zoneA` · `pi7` · `go1-001` | `entity` 는 `entity_id`, 없으면 `source_id` |
| `channel` | `state`·`heartbeat` | 🔴 **`status` 는 안 온다** |
| `ts`·`seq` | ISO · 정수 | `seq` 는 이상하면 예외 대신 **`0`** 이 온다 |
| `payload` | **원래 메시지 통째** | 3층이 아니다 — [§3](#s3) ① |
| `quality`·`aggregation`·`coordinate_frame` | `"good"` · `"raw"` · `null` | **잠정 고정값.** 먼저 맞출 필요 없다고 합의됨 |
| `scope` | 내 구독의 `scope` 를 되돌려준다 | 없으면 `"all"` |

**선택자 축 셋** — `node` 축이 **`node_id` 와 `zone_id` 둘 다** 본다.
지금 보내는 `{entity:'*', node:<zone>, channel:'*'}` 모양을 **그대로 두면 된다.**
⚠ **깨진 선택자는 전량 푸시로 안 물러선다 — 0건이다.**

**없는 것:** `hello` · `subscribed` · 구독 즉시 스냅샷. (`unsubscribe` 는 받는다.)

### `/media` 로 받는 것

```
[4B big-endian 헤더길이][JSON 헤더(UTF-8)][페이로드]
```

| 필드 | 필수 | 주의 |
|---|---|---|
| `frame_ref` | ✅ | **객체** `{source_id, capture_timestamp, sequence_id}` |
| `encoding`·`keyframe`·`width`·`height` | ✅ | `width`/`height` 가 **탐지 `bbox_space.reference` 와 같은 자리**다 |
| `codec` | 선택 | **헤더 값을 그대로** `VideoDecoder` 에 넣는다. 상수 금지 |
| `correlation_id` | 선택 | 표시용. `frame_ref` **밖**에 있다 |

### 헷갈리는 축 셋

| 짝 | 구분 |
|---|---|
| `target_entity_id` ↔ 미디어 `source_id` | **개체 `go1-001`** ↔ **카메라 `go1-001_front`**. 체계는 같고 **값이 다르다** |
| `origin.kind` ↔ `origin_kind` | 탐지 **정밀도**(`safety_minimal`/`precise`) ↔ 원천 **종류**(`real`/`simulation`/`replay`) |
| `node_id` ↔ `node_ref` | 발행 **물리 노드**(허용 라벨) ↔ 임무 **DAG 노드**(금지 라벨) |

> `capture_timestamp` 는 **촬영 시각이 아니다** — 엣지가 프레임 경계를 확정한 시각이고
> 말단 내부 지연이 포함되며 보정되지 않았다. **staleness 는 도착 시각으로 잰다.**
