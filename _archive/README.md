# _archive — 현행이 아닌 파일 보관소

여기 있는 파일은 **지웠다는 뜻이 아니라, 현행이 아니라는 뜻**입니다.
루트와 `reports/assets/`를 열었을 때 지금 유효한 것만 보이게 하려고 옮겼습니다.

**보고서(`reports/*.md`) 본문은 손대지 않았습니다.** 보고서는 그 시점의 기록이므로
당시 파일 이름을 그대로 두는 것이 맞습니다. 보고서에서 아래 이름을 만나면 이 폴더를 보세요.

### 갱신이 필요한 문서

- **`구현계획서.md` (v0.3.1, 2026-08-18)** — 근거가 `요구사항정의서.md` **v0.2**인데 현행은 v0.4다.
  그 사이에 파트 경계·계약·구현 순서가 모두 바뀌었고, 트윈 화면을 Unity 별도 앱으로 가는 결정도
  반영돼 있지 않다. 마일스톤 순서(노드 에디터 최우선)도 현재 판단과 다르다.
  **아카이브가 아니라 개정 대상이다.**
- **`web-dashboard/prototype.html`** — React 앱으로 정식 이관돼 더는 쓰지 않는다.
  다만 `web-dashboard/` 정리는 이번 범위가 아니라 손대지 않았다.
