## 1. 핵심 요약
- 교량의 외관 점검을 위해 촬영한 영상에서 추출한 입면정사영상(정사투영된 교량 입면 이미지) 데이터셋으로, 교량 등급·종류의 다양성을 반영해 수집되었다.
- 교량 균열, 박락, 백태, 누수, 함몰, 요철, 강재 부식, 강재 박리 등 다양한 결함 영역이 라벨링되어 있어 교량 안전관리·구조물 외관조사 AI 개발에 활용할 수 있도록 구축되었다.
- WebFetch로 접근한 페이지 요약 기준 이미지 수는 420,074장으로 확인되었다(§6 신뢰도 참고). 다운로드는 AI-Hub 페이지에서 승인 절차를 거쳐야 하며, K-ICT 빅데이터센터의 데이터 안전구역을 통한 오프라인 분석도 안내되어 있다(WebSearch로 확인).

## 2. 문서 목적
- 해결하려는 문제: 다양한 등급·종류의 교량 외관을 점검할 때, 균열·박락·백태·누수·함몰·요철·강재부식·강재박리 등 여러 결함 유형을 사람이 일일이 육안 조사하는 대신 AI로 탐지하려면 정사투영된 입면 이미지 기반 학습 데이터가 필요하다는 문제.
- 기술적 목표: 서로 다른 등급·종류의 교량에서 촬영한 영상을 입면정사영상으로 가공하고, 결함 영역을 라벨링해 교량 외관조사 AI 모델의 학습·검증에 쓸 수 있게 하는 것.
- 다루는 범위: 원천 입면정사영상과 결함 영역 라벨(구체적 라벨 형식 — 폴리곤 세그멘테이션인지 바운딩박스인지 — 는 이번 조회로 확인 안 됨)을 포함한다.

## 3. 핵심 개념 상세

### 입면정사영상(Orthophoto of Bridge Elevation)
- 정의: 교량 입면(측면)을 정사투영(orthographic projection)방식으로 촬영·가공한 영상으로, 일반 사진과 달리 원근 왜곡이 보정되어 실제 치수·위치 대응이 가능한 형태로 추정된다(용어 자체의 일반적 정의; 이 데이터셋 특유의 가공 파이프라인 세부는 이번 조회로 확인 안 됨).
- 역할: 교량 표면의 결함 위치를 실제 좌표·치수와 연결해 관리할 수 있게 하는 입력 형태로, 일반 사진 기반 결함 탐지보다 정량적 이력 관리에 유리할 것으로 추정된다.

### 다중 결함 유형 라벨링
- 정의: 균열, 박락, 백태, 누수, 함몰, 요철, 강재 부식, 강재 박리 등 8종 이상의 결함 유형이 함께 라벨링되어 있다(AI-Hub 페이지 설명, WebFetch 확인).
- 역할: 콘크리트계 결함(균열·박락·백태·누수 등)과 강재계 결함(부식·박리)을 함께 다룬다는 점에서, 이 저장소 AI-S-07(업무 목적별 요구 근거 정의) 관점의 참고 사례가 될 수 있다 — 동일 교량이라도 콘크리트 점검 목적과 강재 점검 목적이 요구하는 결함 유형이 다를 수 있음을 시사한다.

## 4. 구조 및 흐름
- 데이터 구축 참여기관 역할 분담: ㈜에스지앤아이(주관), ㈜올포랜드, ㈜무한정보기술, ㈜지디에스컨설팅그룹, ㈜제이와이시스템즈, 광운대학교 산학협력단(참여) — WebFetch 페이지 요약 기준.
- 접근 절차: AI-Hub 웹사이트에서 데이터셋 소개 페이지를 확인한 뒤 다운로드 버튼으로 승인을 신청해야 하며, K-ICT 빅데이터센터의 데이터 안전구역(오프라인 분석 공간)을 통한 접근 경로도 별도로 안내된다(WebSearch로 확인). API 다운로드 파일은 분할 압축되어 있어 리눅스 명령으로 병합·압축 해제가 필요하다고 안내된다.

## 6. 한계 및 부족한 점
- **접근 방식과 신뢰도**: 이 문서는 AI-Hub 상세페이지(dataSetSn=71774)에 로그인 없이 WebFetch로 접근해 얻은 소개 페이지 텍스트 요약에 기반한다. 실제 데이터 다운로드나 파일 구조·라벨 스키마 직접 검증은 하지 않았다.
- **정량 수치**: 이미지 수 420,074장은 WebFetch의 페이지 요약 결과로, AI-Hub 원문 화면을 사람이 직접 캡처해 재확인한 것은 아니다.
- **라이선스**: 페이지 상에 명시적 라이선스 조건이 제공되지 않았다 — 실제 사용 시 AI-Hub 이용약관과 승인 절차를 별도로 확인해야 한다.
- **다운로드 실물 접근**: WebSearch 결과에 따르면 다운로드에는 승인이 필요하고 K-ICT 빅데이터센터의 안전구역 이용 안내도 있다 — 이는 일반적인 완전 공개 다운로드가 아니라 절차를 거친 접근이라는 뜻으로, "AI-Hub는 로그인이 필요할 수 있다"는 원 우려가 실제로 부분적으로 맞았음을 보여준다.
- 등록연도, 정확한 라벨 형식, 촬영 장비(드론/차량탑재 등), 해상도는 이번 조회로 확인하지 못했다.
