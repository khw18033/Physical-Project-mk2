# ISO 22166-202:2025

## 메타데이터
- categories: [[Service Robot]], Software Module, Information Model
- domain: [[디지털트윈·상호운용]], [[로보틱스·다중로봇]]
- source: ISO. "Robotics — Modularity for service robots — Part 202: Information model for software modules."
- url: https://www.iso.org/standard/84589.html
- year: 2025
- authors: ISO/TC 299 Robotics
- venue: International Standard

## 1. 핵심 요약
- 서비스 로봇 software module의 information model에 대한 요구사항과 권고를 규정한다.
- interface, property, composition, execution-specific information을 중심으로 다룬다.
- 안전 표준은 아니지만 software module에 필요한 safety-related information을 포함한다.

## 2. 문서 목적
software module 또는 software-related interface가 있는 module의 특성을 구조적으로 정의하고, 설계·개발과 runtime에서 정보를 사용하도록 한다.

## 3. 핵심 개념 상세
- **Interface:** variable과 method 두 유형으로 분류해 기술한다.
- **Composition:** software module 사이의 구성 정보를 다룬다.
- **Execution-specific information:** 실행과 관련된 module 정보를 포함한다.
- **Lifecycle:** 설계, 개발, 운영, 유지보수 단계에 적용할 수 있다.

## 4. 구조 및 흐름
ISO 22166-1의 아홉 원칙과 관련된 software module 정보 모델을 정의하며, module 특성을 interface·property·composition·실행 정보로 구조화한다.

## 5. 핵심 주장과 근거
| 주장 | 근거 |
|---|---|
| safety-related information을 기술하지만 안전 표준은 아니다 | ISO 공개 초록이 두 사실을 함께 명시 |
| runtime과 설계·개발 단계에서 사용된다 | 공개 초록의 이용 단계 설명 |

## 6. 한계 및 부족한 점
- 전체 61쪽 원문은 유료다. 이 문서는 ISO 공식 공개 초록 이외의 세부 field를 복제하거나 추정하지 않는다.
- 공개 초록만으로 schema 호환성이나 conformity 절차를 판단할 수 없다.
