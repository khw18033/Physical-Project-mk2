# A Reference Model for Common Understanding of Capabilities and Skills in Manufacturing

- authors: Aljosha Köcher et al.
- venue: at–Automatisierungstechnik 71(2), 94–104

## 1. 핵심 요약
- 제조 resource function을 vendor-neutral하고 machine-readable하게 설명하기 위한 capability·skill reference model을 제안한다.
- 여러 조직의 Plattform Industrie 4.0 working group이 공동 개발했다.
- capability, skill, service의 정의와 관계를 공통화하여 표준화의 기반을 제공한다.

## 2. 연구 목적
조직과 사용 사례마다 capability와 skill 용어가 다르게 쓰여 상호운용과 표준화가 어려운 문제를 해결한다.

## 3. 핵심 개념 상세
- **Capability:** resource가 달성할 수 있는 구현 독립적 기능을 표현한다.
- **Skill:** capability를 실행 가능하게 구현한 요소다.
- **Service/interface:** skill의 기능에 접근하는 수단과 연결된다.

## 4. 구조 및 흐름
추상 capability를 resource에 연결하고, 이를 실현하는 executable skill과 외부 접근 service/interface를 구분한다.

## 5. 핵심 주장과 근거
| 주장 | 근거 |
|---|---|
| 공통 정의는 vendor-neutral 정보 교환에 필요하다 | 논문 초록이 vendor-neutral, machine-readable model 필요성을 제시 |
| reference model은 후속 표준화의 기반이다 | 초록이 basis for further standardization efforts로 설명 |

## 6. 한계 및 부족한 점
- 제조 영역의 reference model이며 범용 AI serving 또는 로봇 안전 protocol을 정의하지 않는다.
- 논문 발행 당시 표준이 아니라 표준화 기반을 제시한 연구 결과다.

## 7. 원문 기반 핵심 문장
> “This model covers definitions of most important aspects of capabilities and skills.”
