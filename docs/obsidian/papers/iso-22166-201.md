# ISO 22166-201:2024

- source: ISO. "Robotics — Modularity for service robots — Part 201: Common information model for modules."
- url: https://www.iso.org/standard/82334.html
- year: 2024
- authors: ISO/TC 299 Robotics
- venue: International Standard

## 1. 핵심 요약
- 서비스 로봇 module의 common information model(CIM)에 대한 요구사항과 지침을 규정한다.
- interoperability, reusability, composability 달성이 목적이다.
- CIM 구조와 attribute·subclass의 의도된 용도와 의미를 다룬다.

## 2. 문서 목적
서비스 로봇을 구성하는 module을 공통 정보 모델로 기술해 서로 다른 module의 조합과 재사용을 지원한다.

## 3. 핵심 개념 상세
- **CIM:** module에 공통으로 적용하는 정보 구조다.
- **Attributes/Subclasses:** 공통 구조를 구체 module 유형에 맞게 상세화한다.
- **범위:** ISO 공개 초록은 service robot 적용을 명시한다.

## 4. 구조 및 흐름
공통 CIM을 상위 구조로 두고 module별 attribute와 subclass가 이를 구체화한다.

## 5. 핵심 주장과 근거
| 주장 | 근거 |
|---|---|
| 공통 정보 모델의 목표는 상호운용·재사용·조합이다 | ISO 공개 초록에 세 목표가 직접 명시됨 |
| service robot에 적용된다 | 공개 초록의 적용 범위 문장 |

## 6. 한계 및 부족한 점
- 전체 58쪽 원문은 유료다. 이 문서는 ISO 공식 공개 초록에서 확인되는 범위만 정리했으며 세부 field를 추정하지 않는다.
- 특정 middleware나 통신 protocol을 공개 초록만으로 확정할 수 없다.

## 7. 원문 기반 핵심 문장
> “This document applies to service robots.”
