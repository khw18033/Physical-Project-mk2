stt-lab — STT 모델 시험 하네스

F13(음성 인터페이스)을 구현하기 전에 어떤 엔진·모델·설정을 쓸지 근거를 만드는 실험용 화면이다. 대시보드가 아니다. 핵심 산출물은 전사문이 아니라 avg_logprob · no_speech_prob · 단어 probability 의 실측 분포다 (REQ-1306).

① 입력

00.0초

registry.json 의 display_name·aliases[] 조합으로 만든 문장이다. 클릭하면 정답 텍스트가 채워지므로, 읽어서 녹음하면 CER이 바로 나온다.

② 설정

device 확인 중…

registry 어휘로 디코딩을 편향시킨다(REQ-1304). 아래 initial_prompt 와는 다른 것이다 — 이쪽은 어휘, 저쪽은 문맥·문체다.

끄고 같은 오디오를 다시 돌리면 무음 구간 환각의 영향을 볼 수 있다.

language=ko 고정 · condition_on_previous_text=False 고정. 짧은 발화에서 언어 오판과 반복 환각을 부르는 두 설정이라 토글로 열어두지 않았다.

사용 설명서

설정을 바꿀 때는 한 번에 하나만 바꾸고 같은 오디오 재실행으로 비교한다. 숫자 하나만 보지 말고 정답 여부와 확률 분포를 함께 본다.

② 설정 용어
  • 엔진: 음성을 글로 바꾸는 구현체. 현재는 faster-whisper를 사용한다.
  • 모델: 클수록 대체로 정확하지만 다운로드·메모리·처리 시간이 늘어난다.
  • hotwords: registry의 설비명과 별칭을 모델이 더 잘 고르도록 편향시킨다.
  • VAD: 무음 구간을 먼저 잘라 무음 환각과 불필요한 계산을 줄인다.
  • initial_prompt: 발화의 문맥과 문체를 알려준다. hotwords와 합치지 않는다.
  • beam size: 여러 문장 후보를 탐색하는 폭. 높이면 느려질 수 있다.
  • temperature: 후보 선택의 무작위성. 재현 비교는 기본값 0을 권장한다.
  • 단어 확률 강조 임계: 화면 색칠 기준일 뿐, 엔진의 판정값을 바꾸지 않는다.
③ 결과 용어
  • 발화: 입력 오디오 길이. VAD 후는 무음을 제외한 길이다.
  • 추론: 모델이 전사하는 데 걸린 시간. 최초 모델 로드 시간은 별도다.
  • RTF: 추론 시간 ÷ 발화 길이. 1 미만이면 재생 시간보다 빠르다.
  • avg_logprob: 세그먼트 평균 로그 확률. 0에 가까울수록 상대적으로 확신이 높다.
  • no_speech_prob: 무음일 확률. 높으면 무음 환각 후보지만 단독 판정은 금물이다.
  • 단어 probability: 단어별 상대 확률. 붉은 단어는 설정한 강조 임계 미만이다.
  • compression: 반복적인 출력 정도. 지나치게 높으면 반복 환각을 의심한다.
④ 정확도 용어
  • CER: 공백을 제외한 음절 편집 오류율. 낮을수록 좋고 명령 비교의 주 지표다.
  • 자모 CER: 초·중·종성 단위 오류율. 받침 하나 오류와 음절 전체 오류를 구분한다.
  • WER: 어절 오류율. 한국어 조사 차이에도 크게 올라가므로 참고용이다.
“추론 중 CUDA 실패” 해결

GPU는 감지됐지만 CUDA/cuDNN DLL을 불러오지 못하면 CPU int8로 자동 전환된다. 전사는 계속되지만 느리며, 이때의 RTF를 GPU 결과로 기록하면 안 된다.

  1. 오류 문구에서 누락된 DLL 이름을 확인한다.
  2. NVIDIA 드라이버와 CUDA 12, cuDNN 9 런타임을 설치한다.
  3. CUDA의 bin 경로가 Windows PATH에 있는지 확인한다.
  4. 서버를 종료하고 새 PowerShell에서 다시 실행한다.
Get-ChildItem "C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA" -Recurse -Filter "cublas64_12.dll" -ErrorAction SilentlyContinue

결과가 없으면 CUDA 12의 cuBLAS 런타임이 설치되지 않은 상태다.

자주 생기는 문제
  • 8799 포트 충돌: $env:STT_LAB_PORT="8800" 후 서버를 실행한다.
  • 반복 문장: VAD를 켜고 무음 구간 및 compression 값을 확인한다.
  • registry 오류: 서버 상단에 출력된 registry 경로와 파일 존재 여부를 확인한다.
  • 모델 다운로드 실패: 인터넷 연결과 모델 캐시 폴더 쓰기 권한을 확인한다.

④ 정확도
